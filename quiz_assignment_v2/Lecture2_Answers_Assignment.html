Q1. Logistic regression's decision boundary is:

  • A. A set of axis-aligned steps
  • B. A hyperplane \(w^\top x+b=0\)
  • C. Always curved
  • D. A Voronoi tessellation
Answer B. \(\sigma(z)\ge0.5\iff z\ge0\), so the boundary is the hyperplane \(w^\top x+b=0\).

Q2. The EW-jamming weight for the bomber class is \(w_9=4.07\). The odds ratio is about:

  • A. 58.5
  • B. 4.07
  • C. 0.98
  • D. 16.6
Answer A. Odds ratio \(=e^{w}=e^{4.07}\approx58.5\): jamming multiplies the odds of 'bomber' 58-fold.

Q3. Why can't logistic regression separate low-slow UAVs from civilian helicopters in an XOR-like layout?

  • A. Too little data
  • B. The sigmoid saturates
  • C. A single hyperplane cannot separate interleaved classes
  • D. Features are not scaled
Answer C. Linear models need interaction features or non-linear methods (RF, RBF-SVM) for XOR-type structure.

Q4. A predicted vehicle box and the true box have an intersection of 1,225 px² and a union of 1,975 px². At the usual IoU threshold of 0.5 the detection is:

  • A. A hit: IoU ≈ 0.62
  • B. A miss: IoU ≈ 0.38
  • C. A miss, because the boxes are not identical
  • D. It cannot be judged without the class label
Answer A. IoU = intersection/union = 1,225/1,975 = 0.62 ≥ 0.5, so it counts as a correct detection.

Q5. Which algorithms require feature standardisation?

  • A. Decision trees and random forests
  • B. Naive Bayes only
  • C. kNN and SVM
  • D. None
Answer C. Distance- and inner-product-based methods are dominated by large-scale features; trees are scale-invariant.

Q6. A node has five equal classes. Its Gini impurity is:

  • A. 0
  • B. 0.5
  • C. 0.8
  • D. 1.0
Answer C. \(1-5(0.2^2)=0.8\).

Q7. Random forests reduce variance mainly by:

  • A. Pruning each tree
  • B. Using a larger learning rate
  • C. Sequentially fitting residuals
  • D. Averaging many trees made less correlated through bootstrap samples and random feature subsets
Answer D. \(\text{Var}=\rho\sigma^2+(1-\rho)\sigma^2/B\): averaging removes the second term; feature sub-sampling lowers \(\rho\).

Q8. A SAR vehicle classifier scores 99% on a benchmark recorded at one depression angle but fails on imagery taken at another angle. The main cause is:

  • A. Too few convolutional layers
  • B. Distribution shift: SAR signatures change strongly with look geometry
  • C. Wrong labels in the benchmark
  • D. SAR images carry no useful shape information
Answer B. SAR returns depend on aspect and depression angle; test on the deployment sensor geometry, not only on the benchmark.

Q9. Boosting differs from bagging because boosting:

  • A. Trains trees independently in parallel
  • B. Trains trees sequentially, each fitting the residuals of the ensemble so far
  • C. Never overfits
  • D. Uses no learning rate
Answer B. \(F_m=F_{m-1}+\eta T_m\), with \(T_m\) fitted to \(y-F_{m-1}(x)\).

Q10. In a hard-margin SVM the margin width is:

  • A. \(\|w\|\)
  • B. \(C\)
  • C. \(1/b\)
  • D. \(2/\|w\|\)
Answer D. Minimising \(\tfrac12\|w\|^2\) maximises the margin \(2/\|w\|\).

Q11. Increasing the SVM soft-margin parameter C:

  • A. Widens the margin and tolerates more violations
  • B. Removes support vectors
  • C. Has no effect with an RBF kernel
  • D. Narrows the margin, penalising violations more (risk of overfitting)
Answer D. Large C approaches the hard margin; the IADS optimum was C=100.

Q12. The kernel trick works because the SVM dual depends on the data only through:

  • A. Inner products \(x_i^\top x_j\)
  • B. Labels
  • C. Feature means
  • D. Distances to the centroid
Answer A. Replace \(x_i^\top x_j\) by \(K(x_i,x_j)=\phi(x_i)^\top\phi(x_j)\) without computing \(\phi\).

Q13. Naive Bayes performed worst on IADS (83.1%) mainly because:

  • A. Features such as PRF and speed are strongly correlated, violating conditional independence
  • B. Too few classes
  • C. It overfits
  • D. It needs scaled features
Answer A. The independence assumption double-counts correlated evidence.

Q14. On the real IADS stream (0.8% bombers), a model with 92.6% accuracy had bomber recall 12.3%. The best single fix is:

  • A. Report accuracy only
  • B. Delete civilian tracks from the test set
  • C. Class weighting or SMOTE on the training fold, plus per-class recall reporting
  • D. Increase k
Answer C. Weighted loss (\(w_{AB}=26.9\)) or SMOTE raised bomber recall to about 89%; always split before oversampling.

Q15. For a rare, high-cost threat class, the most informative evaluation is:

  • A. Overall accuracy
  • B. ROC-AUC on a balanced lab set only
  • C. Training accuracy
  • D. Precision-recall / average precision and \(F_2\) at the operational base rate
Answer D. With rare positives, FPR hides the volume of false alarms; \(F_2\) weights recall twice as much as precision.

Part B — Assignment

Instructions. Five problems, 100 marks, about 3 hours, plus a 20-mark bonus problem (Problem 6). Show all working. Reference: Lecture 2 reference text.

Problem 1: Metrics on the operational stream 20 marks

On 10,000 real tracks containing 80 adversary bombers, a classifier gives TP = 72, FN = 8, FP = 150, TN = 9,770 for the bomber class.

(a) Compute accuracy, precision, recall, $F_1$ and $F_2$. [8]
(b) Lowering the threshold gives TP = 76, FP = 400. Recompute precision, recall and $F_2$. [6]
(c) Which threshold would you recommend for an IADS, and why might $F_2$ disagree with an operator's view? [6]

Show full solution

(a) Accuracy $=(72+9770)/10000=98.4\%$. $P=72/222=0.324$; $R=72/80=0.900$; $F_1=2(0.324)(0.9)/(1.224)=0.477$; $F_2=5PR/(4P+R)=1.458/2.196=\mathbf{0.664}$. The 98.4% accuracy hides that two of every three alarms are false.

(b) $P=76/476=0.160$; $R=76/80=0.950$; $F_2=5(0.160)(0.95)/(0.640+0.95)=0.760/1.590=\mathbf{0.478}$.

(c) By $F_2$ the original threshold is better (0.664 vs 0.478): 4 extra bombers cost 250 extra false alarms. An operator may still prefer the lower threshold if a single missed bomber is catastrophic and a second sensor can cheaply clear false alarms; the right choice depends on explicit costs, workload and the availability of a second-stage check, which $F_\beta$ only approximates.

Problem 2: Choosing a tree split 20 marks

A node holds 100 tracks: 40 AB and 60 FF. Split A gives left (30 AB, 10 FF) and right (10 AB, 50 FF). Split B gives left (40 AB, 30 FF) and right (0 AB, 30 FF).

(a) Compute the parent Gini impurity. [3]
(b) Compute the weighted child impurity and Gini reduction for each split. [10]
(c) Which split does CART choose? Comment on why split B, despite a pure child, loses. [7]

Show full solution

(a) $G=1-(0.4^2+0.6^2)=0.48$.

(b) Split A: left $G=1-(0.75^2+0.25^2)=0.375$; right $G=1-((1/6)^2+(5/6)^2)=0.278$; weighted $0.4(0.375)+0.6(0.278)=0.317$; reduction $\mathbf{0.163}$. Split B: left $G=1-((4/7)^2+(3/7)^2)=0.490$; right $G=0$; weighted $0.7(0.490)=0.343$; reduction $\mathbf{0.137}$.

(c) CART chooses A. Split B purifies only 30 FF tracks and leaves a large, very mixed left node (70 tracks, impurity 0.49). Split A makes both children substantially purer. Impurity reduction weights each child by its size, so a small pure child does not compensate for a large impure one.

Problem 3: SVM geometry and slack 20 marks

A linear SVM has $w=(3,4)$, $b=-10$; classes $y\in\{-1,+1\}$.

(a) Compute the margin width. [4]
(b) Classify $x_1=(4,2)$ and $x_2=(1,1)$ and compute each point's distance to the boundary. [6]
(c) Compute the slack $\xi$ for $(2,1)$ with $y=+1$ and for $(3,1)$ with $y=-1$, and interpret. [6]
(d) Explain how increasing $C$ would change the solution. [4]

Show full solution

(a) $\|w\|=5$; margin $=2/5=\mathbf{0.4}$.

(b) $f(x_1)=12+8-10=10>0\Rightarrow+1$; distance $10/5=2.0$. $f(x_2)=3+4-10=-3<0\Rightarrow-1$; distance $3/5=0.6$.

(c) $(2,1)$, $y=+1$: $f=6+4-10=0$, $y f=0$, $\xi=\max(0,1-0)=\mathbf{1}$ --- exactly on the boundary. $(3,1)$, $y=-1$: $f=9+4-10=3$, $yf=-3$, $\xi=1-(-3)=\mathbf{4}$ --- misclassified ($\xi>1$) and far on the wrong side.

(d) Larger $C$ penalises slack more: the optimiser narrows the margin (larger $\|w\|$) to reduce violations, fitting the training data more closely at greater risk of overfitting; very large $C$ approaches the hard-margin SVM.

Problem 4: Bayes with realistic priors 20 marks

PRF is Gaussian: FF $\mu=1040,\sigma=185$; AB $\mu=2280,\sigma=310$ (Hz). A track has PRF 1,950 Hz.

(a) Compute the two class-conditional densities. [8]
(b) Compute $P(\text{AB}\mid x)$ with equal priors and with operational priors $P(\text{AB})=0.01$, $P(\text{FF})=0.99$. [8]
(c) A second feature, speed, is strongly correlated with PRF for bombers. Explain what Naive Bayes will do wrong if it is added. [4]

Show full solution

(a) FF: $z=4.92$, $\phi(z)=0.3989e^{-12.10}=2.21\times10^{-6}$, density $=\phi/\sigma=1.20\times10^{-8}$. AB: $z=-1.065$, $\phi=0.3989e^{-0.567}=0.226$, density $=0.226/310=7.30\times10^{-4}$.

(b) Equal priors: $P(\text{AB}|x)=7.30\times10^{-4}/(7.30\times10^{-4}+1.20\times10^{-8})\approx\mathbf{0.99998}$. Operational priors: numerators $0.01(7.30\times10^{-4})=7.30\times10^{-6}$ and $0.99(1.20\times10^{-8})=1.19\times10^{-8}$, so $P(\text{AB}|x)\approx\mathbf{0.998}$. The evidence is so strong here that even a 1% prior leaves the posterior high; for weaker evidence the prior would dominate (base-rate effect).

(c) Naive Bayes multiplies the two likelihoods as if independent, effectively counting the same evidence twice. Posteriors become over-confident, and when the features disagree in unusual ways the classifier can be confidently wrong. Remedies: drop one feature, decorrelate (e.g. PCA), or model the joint distribution.

Problem 5: Ensembles and imbalance 20 marks

(a) Trees have prediction variance $\sigma^2=0.04$ and pairwise correlation $\rho=0.3$. Compute the ensemble variance for $B=1,10,500$ and the limit as $B\to\infty$. What would reduce the limit? [8]
(b) A training set has 5,000 civilian, 600 friendly, 120 UAV, 40 missile and 20 bomber tracks. Compute the class weights $w_c=N/(C\,N_c)$. [6]
(c) A colleague applies SMOTE to the full dataset, then splits into train and test, and reports bomber recall 0.99. Explain the flaw and the correct procedure. [6]

Show full solution

(a) $\text{Var}=\rho\sigma^2+(1-\rho)\sigma^2/B=0.012+0.028/B$. $B=1$: 0.040; $B=10$: 0.0148; $B=500$: 0.012056; limit 0.012. Only lowering $\rho$ (more randomisation: smaller $m$, sub-sampling) or $\sigma^2$ reduces the floor; more trees cannot.

(b) $N=5780$, $C=5$, $N/C=1156$. Civilian $1156/5000=0.23$; friendly $1.93$; UAV $9.63$; missile $28.9$; bomber $\mathbf{57.8}$.

(c) Synthetic test bombers are interpolations of training bombers, so the test set leaks training information and recall is grossly inflated. Correct: split first (stratified), apply SMOTE (or class weights) only inside the training folds of cross-validation, and evaluate on untouched real test data, ideally at the operational class mix.

Problem 6 (bonus): Scoring a vehicle detector on satellite imagery 20 marks

A scene contains 6 vehicles (V1–V6). The true box of V2 has corners $(100,100)$–$(140,130)$ pixels. The detector returns 9 boxes, sorted by confidence, each listed with the vehicle it overlaps most and that IoU:

Rank123456789
Confidence0.970.930.900.850.800.740.600.520.41
Best matchV1V2V1V3V4V5noneV4V6
IoU0.81?0.550.720.300.5800.680.45

(a) Detection 2 has corners $(105,98)$–$(147,128)$. Compute its IoU with V2. [4]
(b) At IoU threshold 0.5, label each detection TP or FP, remembering that each true vehicle can be matched only once. [4]
(c) Compute running precision and recall, and the interpolated average precision. [8]
(d) Recompute AP at a stricter IoU threshold of 0.7 and explain what the drop tells an imagery analyst. [4]

Show full solution

(a) Overlap in $x$: $105$ to $140$ = 35 px; in $y$: $100$ to $128$ = 28 px; intersection $=980$. Areas: true $40\times30=1{,}200$, predicted $42\times30=1{,}260$. Union $=1{,}200+1{,}260-980=1{,}480$. IoU $=980/1{,}480=\mathbf{0.66}$.

(b) TP, TP, FP (V1 already matched by detection 1: a duplicate), TP, FP (IoU 0.30), TP, FP (no vehicle: decoy or clutter), TP (V4 at 0.68 — V4 was not matched by detection 5), FP (IoU 0.45 < 0.5). Five TPs; V6 is never found.

(c) Precision: 1.00, 1.00, 0.67, 0.75, 0.60, 0.67, 0.57, 0.63, 0.56. Recall (of 6): 0.17, 0.33, 0.33, 0.50, 0.50, 0.67, 0.67, 0.83, 0.83. Interpolated precision at each recall step (the best precision at that recall or beyond): 1.00 at 0.17 and 0.33; 0.75 at 0.50; 0.67 at 0.67; 0.63 at 0.83. AP $=\frac16(1.00+1.00+0.75+0.67+0.63)=\mathbf{0.67}$. Recall never reaches 1, so the last sixth of the curve contributes nothing.

(d) At 0.7 only detections 1 (0.81) and 4 (0.72) count. Precision 1.00, 0.50, 0.33, 0.50, 0.40, …; recall reaches only $2/6$. AP $=\frac16(1.00)+\frac16(0.50)=\mathbf{0.25}$. The detector usually finds vehicles but localises them loosely. For counting and cueing that may be acceptable; for precise targeting or measuring vehicle dimensions it is not. Report AP at the IoU the mission needs, and note that the decoy (detection 7) scored 0.60 confidence — a deception risk to test explicitly.
