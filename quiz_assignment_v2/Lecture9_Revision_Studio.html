Part 4How the methods connect

Forty methods, far fewer ideas. Learn these links and an unseen question becomes a familiar one.

logistic regression → neuron → softmax policy

One neuron, three names

The cross-entropy gradient (1ₐ − p)x and the REINFORCE gradient (1ₐ − π)x·G differ only in what multiplies them: a label or a return.

GMM / EM → (σ → 0) → k-means

k-means is hard EM

Shrink equal spherical covariances to zero and soft responsibilities become nearest-centroid assignments.

inverse-variance weighting = Kalman = Bayes

Combining uncertain sources

The same formula fuses sensors, updates POMDP beliefs and pools studies in a meta-analysis.

ridge = Gaussian prior · lasso = Laplace prior

Regularisation is a prior

Weight decay and the KL penalties of PPO and SAC are the same idea: stay near a reference unless the data insist.

Bellman → value iteration → Q-learning → DQN

Five steps from equation to agent

Each step trades exactness for scale, and each brings a new failure mode, ending with the deadly triad.

gradient descent on functions = boosting

Boosting fits gradients

Each new tree fits the negative gradient of the loss; learning rate and early stopping work as they do for weights.

Nadaraya–Watson → self-attention

Attention is kernel regression

A Transformer layer is a learned, data-dependent weighted average of values.

PCA → linear autoencoder → anomaly score

Reconstruction error

Data that the main structure cannot reconstruct are, by definition, unusual: the basis of Lecture 5.
