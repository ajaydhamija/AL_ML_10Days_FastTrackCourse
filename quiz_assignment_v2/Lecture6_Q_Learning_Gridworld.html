DEMO 2Value iteration: planning with a model

If the transition model is known, no trial and error is needed. Each sweep applies the Bellman optimality update V(s) ← maxa Σ P(s′|s,a)[r + γV(s′)] to every cell. Values spread outward from the objective one step per sweep, and the change Δ shrinks by at least a factor γ each time.

DEMO 3The discount factor sets the horizon

A reward t steps away is worth γt of the same reward now. The effective horizon 1/(1−γ) is roughly how far ahead the agent looks. Should it take a small reward now or a larger one later?

DEMO 4Why max overestimates, and how Double DQN fixes it

Suppose every action is truly worth 0 but the agent's estimates carry noise. The DQN target uses maxa Q̂(s′,a), and the maximum of noisy estimates is biased upward. Double DQN chooses the action with one estimate and evaluates it with another, independent one.
