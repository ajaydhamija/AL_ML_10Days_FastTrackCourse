Q1. The core difficulty that breaks single-agent convergence guarantees in MARL is:

  • A. Large networks
  • B. Continuous actions
  • C. Discounting
  • D. Non-stationarity: other agents are learning, so each agent's environment keeps changing
Answer D. From one agent's view, teammates and opponents are part of a changing environment.

Q2. In a Dec-POMDP each agent acts on:

  • A. The full global state
  • B. The other agents' rewards
  • C. Its own private observation (or history)
  • D. A shared policy only
Answer C. Partial observability per agent: a drone sees 200 m, a tank 500 m.

Q3. CTDE means:

  • A. Global information is used in training; each agent acts on local observations at execution
  • B. Centralised execution
  • C. No training
  • D. Communication is mandatory in the field
Answer A. Like mission command: rehearse with full intelligence, execute under radio silence.

Q4. Independent Q-learning scored 58.3% because it:

  • A. Used too many parameters
  • B. Ignores teammates' learning and coordination
  • C. Uses CTDE
  • D. Uses communication
Answer B. It is the baseline floor for MARL.

Q5. The IGM property ensures that:

  • A. Each agent acting greedily on its own Q gives the joint greedy action of \(Q_{tot}\)
  • B. Agents share rewards
  • C. Agents communicate
  • D. Learning is on-policy
Answer A. Decentralised execution consistent with centralised training.

Q6. QMIX guarantees IGM by enforcing:

  • A. \(Q_{tot}=\sum Q_i\)
  • B. Zero-sum rewards
  • C. \(\partial Q_{tot}/\partial Q_i\ge0\) via non-negative mixing weights from hypernetworks
  • D. A shared actor
Answer C. Monotonic, state-conditioned non-linear mixing; strictly more expressive than VDN's sum.

Q7. Which situation can QMIX NOT represent well?

  • A. Every agent's best action is independent
  • B. Discrete actions
  • C. Agents share a reward
  • D. One agent's best action depends on another's choice (advance only if the other holds)
Answer D. Non-monotonic coordination violates the mixing constraint.

Q8. MAPPO's parameter sharing means:

  • A. Agents share rewards
  • B. The critic is shared with the enemy
  • C. Agents share observations at execution
  • D. All agents use one actor network (with an agent ID input), so every agent's experience trains it
Answer D. Fewer parameters, better sample efficiency.

Q9. MAPPO 82.4% vs human team 81.3% from one evaluation shows:

  • A. Comparable performance; the gap is within likely sampling error and simulation caveats apply
  • B. AI is clearly superior
  • C. Humans are superior
  • D. The test is invalid
Answer A. With ~300 episodes each rate has a standard error near 2.2 points.

Q10. MADDPG gives each agent:

  • A. A shared Q-table
  • B. No critic
  • C. Its own centralised critic conditioned on all agents' actions
  • D. A mixing network
Answer C. Suits continuous actions and mixed cooperative-competitive settings.

Q11. The free-rider problem in a shared team reward is:

  • A. Idle or unhelpful agents receive the same credit as critical ones
  • B. Agents over-explore
  • C. Rewards are too sparse
  • D. Communication is jammed
Answer A. Naive equal split gives +16.7 to every agent.

Q12. COMA's counterfactual baseline for agent i is:

  • A. The team's average reward
  • B. The expected joint value if agent i acted according to its policy while others' actions stay fixed
  • C. Agent i's last reward
  • D. Zero
Answer B. \(A_i=Q(s,\mathbf a)-\sum_{a'}\pi_i(a')Q(s,(a',\mathbf a_{-i}))\).

Q13. CommsMAPPO's learned 8-D messages were found (by probes) to encode:

  • A. Random noise
  • B. Reward values
  • C. Exact coordinates of the objective
  • D. Enemy positions, SAM lock-on status and fuel state
Answer D. An emergent code; it must be decoded and secured against spoofing.

Q14. Agents learning to conserve ammunition by not firing is an example of:

  • A. Correct doctrine
  • B. Reward mis-specification producing locally rational but tactically bad behaviour
  • C. Communication failure
  • D. Overfitting to humans
Answer B. Agents optimise what you reward, not what you meant.

Q15. The course's position on lethal autonomy is:

  • A. Level 4 is acceptable with good rewards
  • B. MARL as Level-2 decision support; humans decide on lethal force, because IHL judgements cannot be encoded in rewards
  • C. Level 3 by default
  • D. No AI in defence
Answer B. Distinction and proportionality are contextual legal judgements requiring accountable humans.

Part B — Assignment

Instructions. Five problems, 100 marks, plus a 20-mark bonus problem (Problem 6). Reference: Lecture 8 reference text.

Problem 1: IGM: VDN versus QMIX 20 marks

Two agents each choose A or B. Individual values: $Q_1(A)=3$, $Q_1(B)=1$; $Q_2(A)=2$, $Q_2(B)=4$.

(a) Under VDN compute $Q_{tot}$ for all four joint actions and verify IGM. [6]
(b) A monotonic mixer is $Q_{tot}=Q_1^2/2+3Q_2$ (with $Q_i\ge0$). Is IGM preserved? Show the joint values. [6]
(c) The true team values are (A,A)=10, (A,B)=2, (B,A)=2, (B,B)=8. Can any monotonic mixer of these individual Qs reproduce this ranking? Explain. [8]

Show full solution

(a) (A,A) 5; (A,B) 7; (B,A) 3; (B,B) 5. Joint max (A,B) = (argmax $Q_1$, argmax $Q_2$) = (A,B): IGM holds.

(b) (A,A) $4.5+6=10.5$; (A,B) $4.5+12=\mathbf{16.5}$; (B,A) $0.5+6=6.5$; (B,B) $0.5+12=12.5$. The mixer increases in both arguments, so the maximum is again (A,B): IGM preserved.

(c) The true optimum (A,A) needs agent 2 to pick A, but agent 2's individual value prefers B whatever agent 1 does. A monotonic $f(Q_1,Q_2)$ always ranks (A,B) above (A,A) because $Q_2(B)>Q_2(A)$. The team value depends on the combination (coordination: both A or both B), which is non-monotonic in the individual values. QMIX cannot represent it with these utilities; it must learn different individual utilities, or a richer factorisation or communication is needed.

Problem 2: Counterfactual credit 20 marks

A team succeeds. For the drone agent the centralised critic gives $Q=70$ for the actual joint action (drone held position). With the other agents fixed, values for the drone's alternatives are: hold 70, overwatch 82, return 60, with policy probabilities 0.5, 0.3, 0.2.

(a) Compute the counterfactual baseline and advantage. [8]
(b) Compare with an equal split of a +120 team reward among 6 agents. [6]
(c) Why does the counterfactual advantage reduce free-riding? [6]

Show full solution

(a) $b=0.5(70)+0.3(82)+0.2(60)=35+24.6+12=71.6$; $A=70-71.6=\mathbf{-1.6}$: holding was slightly worse than the drone's average choice.

(b) An equal split gives every agent +20, so the drone would be rewarded for holding position when overwatch was better.

(c) Each agent is credited only for the difference its own action made relative to its alternatives, with teammates held fixed. An idle agent gains nothing from teammates' successes and is pushed toward helpful actions.

Problem 3: Is the AI really better than the experts? 20 marks

MAPPO succeeded in 247 of 300 evaluation missions; the human planner team in 122 of 150.

(a) Compute both success rates and their standard errors. [6]
(b) Test whether the difference is significant (two-proportion z-test). [8]
(c) List three further reasons to be cautious before claiming the AI outperforms humans. [6]

Show full solution

(a) MAPPO $247/300=82.3\%$, SE $=\sqrt{0.823(0.177)/300}=2.2\%$. Humans $122/150=81.3\%$, SE $=\sqrt{0.813(0.187)/150}=3.2\%$.

(b) Pooled $\hat p=369/450=0.82$; SE $=\sqrt{0.82(0.18)(1/300+1/150)}=0.0384$; $z=0.010/0.0384=0.26$; $p\approx0.79$. No evidence of a difference.

(c) Simulation vs reality (sim-to-real gap); a fixed scenario and opponent (humans adapt across scenarios, the AI may not); humans worked with communications while MAPPO is evaluated without; possible exploitability of a fixed learned policy; one training seed, with no variance across runs reported.

Problem 4: Designing a MARL system 20 marks

Design a MARL system for a naval task group: three escorts and two helicopters defending a high-value unit against air and surface threats, with intermittent communications.

(a) Formulate the Dec-POMDP: agents, observations, actions, reward. [8]
(b) Choose between QMIX and MAPPO and justify. [6]
(c) How will you detect and prevent degenerate emergent behaviour? [6]

Show full solution

(a) Agents: 5 platforms. Observations: own sensors (radar/sonar tracks within range), own weapons and fuel state, last received allied picture. Actions: manoeuvre, sensor mode, engage/hold, launch/recover helicopter, communicate (if available). Team reward: survival of the high-value unit, threats neutralised, minus own losses, minus fuel and munitions use, with large penalties for engaging neutral contacts.

(b) MAPPO with a centralised critic and parameter sharing (an agent-type ID distinguishes escorts from helicopters): it is robust, handles heterogeneous agents and mixed discrete actions, and policies execute decentrally when communications drop. QMIX is attractive if actions are purely discrete and off-policy data reuse is critical, but its monotonic mixing may miss the strongly coordinated behaviours (e.g. layered engagement sequencing) this task needs.

(c) Audit replays for exploits (holding fire, hiding behind the high-value unit); add explicit constraints rather than penalties for safety-critical rules; evaluate against diverse and adaptive opponents (league play); red-team; probe learned messages; deploy only at Level 2 with human approval of engagements and full logging.

Problem 5: Autonomy and IHL 20 marks

A programme office proposes deploying the CommsMAPPO policy at Level 3 because it ``beats human experts''.

(a) Write a structured brief (around 250 words) recommending an autonomy level, citing at least four technical and legal arguments. [14]
(b) Specify the human--machine interface and audit requirements for your recommended level. [6]

Show full solution

(a) A model answer recommends Level 2. Arguments: (1) the performance claim rests on simulation; transfer gaps of 15–20 points are typical (drones 94% → 78%); (2) the human-vs-AI difference is not statistically established; (3) a learned fixed policy can be probed and exploited by an adaptive adversary, and emergent communication can be spoofed; (4) reward penalties cannot guarantee IHL distinction and proportionality, which are contextual legal judgements; (5) accountability requires an identifiable human decision for each lethal action; (6) degenerate behaviours (e.g. holding fire) show that reward mis-specification persists. Level 2 captures the speed benefit of AI planning while retaining human judgement for engagements.

(b) The interface should present the top recommended actions with their values, confidence or uncertainty, and reasons (salient threats, SHAP-style attributions); require explicit approval for any engagement; provide override and abort; flag out-of-distribution situations. Audit: log sensor inputs, AI recommendations, human decisions, timestamps and outcomes, retained for after-action and legal review.

Problem 6 (bonus): Credit, commitment and claims 20 marks

(a) A four-agent team earns $G=80$. Re-simulating with each agent replaced by an idle default gives 30 (without A), 74 (without B), 55 (without C) and 80 (without D). Compute the difference rewards and comment. [5]
(b) One patrol covers target 1 with probability $c$ and target 2 otherwise. Attacker payoffs: target 1 uncovered $+8$, covered $-4$; target 2 uncovered $+5$, covered $-2$. Defender: target 1 $-8$/$+4$; target 2 $-5$/$+2$. Find the optimal coverage, and compare the defender's payoff with a 50/50 patrol. [7]
(c) A MARL team won 85% of 120 engagements; the human team won 79% of 120. Test the difference, and estimate roughly how many engagements per side would be needed for it to reach significance at the 5% level if the rates held. [5]
(d) Agent X (Elo 1580) plays agent Y (1450). Give X's expected score, and X's new rating after a loss with $K=24$. [3]

Show full solution

(a) A $\mathbf{50}$, B $\mathbf{6}$, C $\mathbf{25}$, D $\mathbf{0}$. D is a free rider: a shared reward would pay it 80 for contributing nothing, and difference rewards remove that incentive. These one-at-a-time differences do not sum to $G$ ($81\ne80$) because contributions interact; Shapley values would divide $G$ exactly.

(b) Attacker payoffs: target 1 $8-12c$; target 2 $-2(1-c)+5c=-2+7c$. Indifference: $8-12c=-2+7c\Rightarrow c=10/19=\mathbf{0.53}$. The attacker then gets 1.68 at either target, and the defender $-1.68$. With a 50/50 patrol the attacker strikes target 1 (payoff 2.0 versus 1.5) and the defender gets $0.5(4)+0.5(-8)=\mathbf{-2.0}$. Optimal randomised commitment improves the defender's expected payoff by 0.32.

(c) $SE=\sqrt{0.85(0.15)/120+0.79(0.21)/120}=0.049$; $z=0.06/0.049=1.21$, $p\approx0.22$: not demonstrated. At about 300 per side $z\approx1.92$ (borderline); at about 500, $z\approx2.48$. The simulation's fidelity and the opponents used matter as much as the sample size.

(d) $E_X=1/(1+10^{-130/400})=\mathbf{0.68}$. After a loss: $1580+24(0-0.68)=\mathbf{1563.7}$.
