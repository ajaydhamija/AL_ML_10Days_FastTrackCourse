Q1. The main advantage of anomaly detection over supervised classification for cyber defence is:

  • A. Higher accuracy on known attacks
  • B. It never raises false alarms
  • C. It is always faster
  • D. It needs no attack labels, so it can detect zero-day threats
Answer D. It models normal behaviour and flags deviations, including never-seen attacks.

Q2. 1,000 individually normal packets in 10 ms is an example of a:

  • A. Point anomaly
  • B. Contextual anomaly
  • C. Collective anomaly
  • D. Label error
Answer C. The group pattern (e.g. a port scan) is anomalous, not any single record.

Q3. With Q1 = 2,840, Q3 = 5,620, the IQR lower fence is:

  • A. 2,840
  • B. -1,330
  • C. 1,330
  • D. 9,790
Answer B. \(Q_1-1.5\times2780=-1330\); a DoS value of 1.2 bytes is therefore NOT below the fence.

Q4. Mahalanobis distance improves on Euclidean distance because it:

  • A. Ignores scale
  • B. Requires labels
  • C. Uses the median
  • D. Accounts for feature variances and correlations through \(\Sigma^{-1}\)
Answer D. Points that break a correlation can be far in Mahalanobis terms while looking ordinary feature by feature.

Q5. Why should the covariance for Mahalanobis detection be estimated robustly (e.g. MCD)?

  • A. To speed computation
  • B. Because data are always Gaussian
  • C. Anomalies in the training data inflate \(\Sigma\) and mask themselves
  • D. To reduce dimension
Answer C. Use the most central 50% of points.

Q6. In an Isolation Forest, anomalies have:

  • A. Short average path lengths
  • B. Long average path lengths
  • C. Path length equal to the tree height
  • D. No path
Answer A. Few, different points are separated by few random splits.

Q7. Isolation Forest uses small sub-samples (\(\psi=256\)) per tree mainly because:

  • A. Memory is limited
  • B. It improves recall of normal points
  • C. Large samples are illegal
  • D. Small samples keep normal points crowded and anomalies isolated, amplifying the contrast (and make it fast)
Answer D. Also gives O(log psi) inference.

Q8. In a one-class SVM, \(\nu=0.05\) means:

  • A. Accuracy is 95%
  • B. The kernel width is 0.05
  • C. 5% of training points may be treated as outliers (upper bound) and at least 5% are support vectors
  • D. 5 clusters
Answer C. Set \(\nu\) near the acceptable false-positive rate.

Q9. An autoencoder detects anomalies because:

  • A. It is trained on attacks
  • B. Trained on normal data, it reconstructs normal inputs well and unusual inputs poorly (high reconstruction error)
  • C. It clusters data
  • D. It uses labels
Answer B. Score = \(\|x-\hat x\|^2\); threshold set for a target FPR.

Q10. The autoencoder threshold \(\tau\) should be chosen by:

  • A. Fixing an acceptable false-positive rate on validation (normal) data
  • B. Maximising test accuracy
  • C. Using the attack mean
  • D. Trial on the test set
Answer A. Fix the false-alarm budget first; the detection rate follows.

Q11. Which attack type was hardest for the autoencoder (92.8% TPR)?

  • A. DoS
  • B. R2L (imitates legitimate logins)
  • C. U2R
  • D. Probe
Answer B. Its features look most like normal traffic.

Q12. Insider-threat detection works better with per-user baselines because:

  • A. Users are identical
  • B. What is abnormal for one user (e.g. weekend logins) is normal for another
  • C. It needs fewer features
  • D. It avoids LSTMs
Answer B. A 02:17 Saturday login was about 4 s.d. from user X's own pattern.

Q13. A first-ever connection from a workstation to the domain controller is a signal of:

  • A. Possible lateral movement
  • B. Normal backup
  • C. DoS
  • D. Label noise
Answer A. Graph methods compare current edges with a historical baseline.

Q14. Even at 0.6% FPR, a network with 1 million packets/day produces about:

  • A. 6 false alerts
  • B. 600
  • C. 6,000
  • D. 60,000
Answer C. \(0.006\times10^6\approx6000\): hence tiered detection and analyst triage.

Q15. In the recommended 3-tier architecture, Isolation Forest is used for:

  • A. Real-time screening of all traffic
  • B. Final confirmation
  • C. Analyst explanation
  • D. Labelling
Answer A. Cheap and fast screening first; autoencoder deep-scan second; analysts third.

Part B — Assignment

Instructions. Five problems, 100 marks, plus a 20-mark bonus problem (Problem 6). Reference: Lecture 5 reference text.

Problem 1: Mahalanobis vs Euclidean 20 marks

Normal traffic on two standardised features has $\mu=(0,0)$ and $\Sigma=\begin{pmatrix}4&2\\2&2\end{pmatrix}$.

(a) Compute $\Sigma^{-1}$. [4]
(b) Compute Euclidean and Mahalanobis distances of $a=(2,2)$ and $b=(2,-2)$. [10]
(c) With a 99% $\chi^2_2$ threshold of 9.21 on $D_M^2$, which point is flagged and why? [6]

Show full solution

(a) $\det\Sigma=8-4=4$; $\Sigma^{-1}=\tfrac14\begin{pmatrix}2&-2\\-2&4\end{pmatrix}=\begin{pmatrix}0.5&-0.5\\-0.5&1\end{pmatrix}$.

(b) Both have Euclidean distance $\sqrt8=2.83$. $a$: $\Sigma^{-1}a=(0,1)$, $D_M^2=a\cdot(0,1)=2$, $D_M=\mathbf{1.41}$. $b$: $\Sigma^{-1}b=(2,-3)$, $D_M^2=4+6=10$, $D_M=\mathbf{3.16}$.

(c) $b$ is flagged ($10>9.21$); $a$ is not. The features are positively correlated: $a$ moves along the correlation and is typical, $b$ breaks it. Euclidean distance cannot tell them apart.

Problem 2: Isolation Forest scores --- and a consistency check 20 marks

(a) Compute $c(\psi)$ for $\psi=256$, using $H(i)\approx\ln i+0.5772$. [5]
(b) Compute $s$ for average path lengths 2.0, 10.2 and 12.0, and interpret. [9]
(c) The lecture reports $s\approx0.41$ for normal HTTP traffic with average path length 6.84 at $\psi=256$. Check this against the formula and comment. [6]

Show full solution

(a) $H(255)=\ln255+0.5772=6.118$; $c=2(6.118)-2(255)/256=12.237-1.992=\mathbf{10.24}$.

(b) $s=2^{-E[h]/10.24}$: $E[h]=2.0\Rightarrow s=2^{-0.195}=\mathbf{0.87}$ (anomaly); $10.2\Rightarrow\approx\mathbf{0.50}$ (typical); $12.0\Rightarrow2^{-1.17}=\mathbf{0.44}$ (deep, normal).

(c) $2^{-6.84/10.24}=2^{-0.668}=0.63$, not 0.41; reaching 0.41 would require $c\approx5.4$. The reported scores and path lengths are not mutually consistent (perhaps different sub-sample sizes or score definitions). Lesson from Lecture 1: recompute headline numbers from their stated inputs before relying on them; here the ranking (attacks scored far higher than normal) still holds.

Problem 3: Autoencoder thresholds and alert volume 20 marks

Normal reconstruction error has mean 0.024 and s.d. 0.018. The network carries 1,000,000 packets/day, 3.6% attacks.

(a) Assuming Gaussian normal RE, what threshold gives FPR 0.6%? Compare with the lecture's $\tau=0.087$. [6]
(b) With TPR 95.8% and FPR 0.6%, compute daily true alerts, false alerts and precision. [8]
(c) Why is an empirical percentile of validation RE better than the Gaussian formula? [6]

Show full solution

(a) $z_{0.994}\approx2.51$; $\tau=0.024+2.51(0.018)=\mathbf{0.069}$. The lecture's 0.087 corresponds to $z=3.5$ under a Gaussian assumption, i.e. a far smaller FPR, unless the true RE distribution has a heavy right tail.

(b) Attacks $=36{,}000$, normal $=964{,}000$. True alerts $=0.958\times36{,}000=34{,}488$; false $=0.006\times964{,}000=5{,}784$; precision $=34{,}488/40{,}272=\mathbf{85.6\%}$.

(c) Reconstruction errors are non-negative and right-skewed, so a Gaussian model misplaces the tail. Taking the 99.4th percentile of RE on held-out normal data sets the FPR directly without distributional assumptions; re-estimate it periodically as normal traffic drifts.

Problem 4: Insider-threat evaluation 20 marks

Among 500 users, 15 are compromised. The LSTM autoencoder flags 16 users: 13 compromised and 3 innocent.

(a) Compute recall, precision, FPR and $F_2$. [8]
(b) Explain why accuracy is useless here. [4]
(c) The two missed accounts belonged to analysts who legitimately work weekends. Propose two features or design changes to catch such cases, with their risks. [8]

Show full solution

(a) Recall $13/15=\mathbf{0.867}$; precision $13/16=\mathbf{0.8125}$; FPR $3/485=\mathbf{0.62\%}$; $F_2=5(0.8125)(0.867)/(4(0.8125)+0.867)=3.522/4.117=\mathbf{0.855}$.

(b) Flagging nobody would be 97% accurate at the user level (99.997% at the event level) while catching no threats.

(c) Examples: (1) data-access combination features (finance + HR + technical files in one session is unusual for anyone) — risk: false alarms for legitimate cross-functional roles; (2) peer-group baselines (compare with similar roles, not only the user's own history, so a slowly poisoned baseline is still caught) — risk: needs role metadata; (3) device/location fingerprinting of credential use — risk: privacy and travel false alarms.

Problem 5: Designing the tiered pipeline 20 marks

Tier 1 Isolation Forest (TPR 91.4%, FPR 1.1%, 0.002 ms/packet); tier 2 autoencoder applied only to tier-1 alerts (TPR 95.8%, FPR 0.6%, 0.04 ms/packet). Traffic: 1,000,000 packets/day, 3.6% attacks. Assume the tiers' errors are independent.

(a) Compute tier-1 alerts, tier-2 alerts (true and false) and overall TPR. [10]
(b) Compare compute time with running the autoencoder on all traffic. [4]
(c) Discuss the trade-off and how you would recover missed attacks. [6]

Show full solution

(a) Tier 1: true $0.914\times36{,}000=32{,}904$; false $0.011\times964{,}000=10{,}604$. Tier 2: true $0.958\times32{,}904=31{,}522$; false $0.006\times10{,}604\approx64$. Overall TPR $=31{,}522/36{,}000=\mathbf{87.6\%}$ with only about 64 false alerts/day.

(b) Tier 1: $10^6\times0.002$ ms $=2$ s; tier 2: $43{,}508\times0.04$ ms $=1.7$ s; total about 3.7 s vs 40 s for the autoencoder on everything.

(c) Serial tiers multiply sensitivities (lower overall TPR than the autoencoder alone, 95.8%) but slash false alarms (64 vs 5,784/day) and compute. Recover misses by lowering the tier-1 threshold (more tier-2 load), periodic full autoencoder sweeps of stored traffic, and analyst-driven threat hunting; feed every confirmed miss back into training.

Problem 6 (bonus): Tuning an intrusion-alert pipeline 20 marks

Normal flows on a defence network have mean bytes $\mu_1=500$, mean duration $\mu_2=20$ s, covariance $\Sigma=\begin{pmatrix}10{,}000&240\\240&16\end{pmatrix}$ (correlation 0.6).

(a) Compute the z-scores and the squared Mahalanobis distance of flow A $(700, 32)$ and flow B $(300, 26)$. Which is flagged at the 99.9% $\chi^2_2$ threshold of 13.82, and why does the answer surprise a univariate analyst? [6]
(b) An Isolation Forest ($\psi=256$, $c=10.24$) gives a flow a mean path length of 4.5. Compute its score. [2]
(c) The network carries $2\times10^6$ flows a day, of which about 30 are malicious; the analysts can handle 150 alerts a day. Two operating points are available: FPR $10^{-4}$ with TPR 0.62, or FPR $5\times10^{-5}$ with TPR 0.48. For each, compute the daily alerts, attacks caught and precision, and choose. [7]
(d) Daily failed-login counts have a normal mean of 40 (s.d. 6). Recent days: 41, 38, 44, 39, 47, 49, 46, 50, 48, 52. Run a CUSUM with $k=3$ and $h=18$ and state when it alarms. [5]

Show full solution

(a) Flow A: z-scores $(2.0,\;3.0)$, $d^2=\mathbf{9.06}$ — not flagged. Flow B: z-scores $(-2.0,\;1.5)$, $d^2=\mathbf{15.39}$ — flagged. Flow A is large in both features, but bytes and duration normally rise together, so the combination is plausible. Flow B is small in bytes yet long in duration, which breaks the correlation — typical of a slow, low-volume beacon. Univariate thresholds would rank A as the more suspicious; Mahalanobis distance ranks them correctly.

(b) $s=2^{-4.5/10.24}=\mathbf{0.74}$: clearly shorter paths than average, so the flow is worth review.

(c) The capacity limit is FPR $\le150/(2\times10^6)=7.5\times10^{-5}$. At $10^{-4}$: about 200 false + 18.6 true = 219 alerts a day, over capacity; precision 8.5%. At $5\times10^{-5}$: about 100 false + 14.4 true = 114 alerts; precision 12.6%; within capacity. Choose $5\times10^{-5}$, but report that it misses about half the attacks, and use the spare capacity (36 alerts) for a second detector with different blind spots.

(d) $S_t=\max(0,S_{t-1}+x_t-43)$: 0, 0, 1, 0, 4, 10, 13, 20 ⇒ alarm on day 8 ($S\ge18$), about four days after the counts began to rise. No single day exceeded the Shewhart limit $40+3\times6=58$.
