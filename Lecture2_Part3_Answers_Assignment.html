Detailed Explanations — All 15 Questions

Q1
Geometric shape of Logistic Regression decision boundary
✅ B — A hyperplane w·x + b = 0 (linear in feature space)
Decision boundary = where P(y|x)=0.5 → σ(z)=0.5 → z=0 → w·x+b=0. A linear equation in d dimensions defines a (d-1)-dimensional hyperplane. For IADS d=11 features: a 10-dimensional hyperplane. LR cannot create curved boundaries without explicit non-linear feature engineering.
Q2
k=1: 100% train, 78.3% val; k=21: 91.8% train, 90.2% val
✅ C — Bias-variance tradeoff: k=1 high variance, k=21 balanced
k=1 kNN has zero training error (trivially classifies each point by itself) but reacts to every noise point — extremely high variance. As k increases, the decision function becomes a smoother average over more neighbours (higher bias, lower variance). The 11.9% train-val gap at k=1 vs only 1.6% at k=21 is the classic variance signature.
Q3
Gini Impurity for 5 equal classes (200 each, N=1000)
✅ D — Gini = 0.80
Gini = 1 − Σ pᵢ² = 1 − (5 × (200/1000)²) = 1 − (5 × 0.04) = 1 − 0.20 = 0.80. Maximum Gini for K equal classes = 1 − 1/K = 1 − 0.2 = 0.80. After the EW Jamming split, weighted Gini = 0.723, giving reduction = 0.077.
Q4
RF reduces Var_ensemble primarily by reducing which variable?
✅ B — ρ (tree correlation) via random feature subsampling
Var_ensemble = ρσ² + (1-ρ)σ²/B. Random feature subsampling (m=√d features per split) prevents trees from all choosing the same dominant features (like EW Jamming), forcing them to specialise on different features → different trees → low ρ. If ρ→0: Var_ensemble→σ²/B → improves with more trees. Bagging alone (same features) gives higher ρ.
Q5
Why XGBoost (400 trees) inference (0.7ms) beats RF (500 trees, 2.8ms)?
✅ A — XGBoost uses shallower trees (max_depth=5), fewer nodes to traverse
At inference, each sample traverses every tree's decision path. XGBoost trees with max_depth=5 have at most 31 leaf nodes, requiring ≤5 comparisons per tree × 400 trees = 2,000 operations. RF unlimited-depth trees may have 1,000s of nodes each, requiring many more comparisons per tree even with only 500 trees.
Q6
What are the 1,247 support vectors in the IADS SVM?
✅ B — Training samples ON or WITHIN the margin boundaries (αᵢ > 0)
In the SVM dual problem, αᵢ > 0 only for samples that lie on the margin (αᵢ > 0, ξᵢ=0), within the margin (0 < αᵢ < C, 0 < ξᵢ < 1), or misclassified (αᵢ=C, ξᵢ>1). Only these 1,247 samples contribute to the decision function — all other training samples have αᵢ=0 and play no role at inference.
Q7
What happens geometrically when γ is very large in RBF kernel?
✅ B — Each point influences a narrow neighbourhood → jagged boundary → overfitting
K(x,x')=exp(-γ||x-x'||²): large γ creates a very narrow Gaussian that peaks sharply and decays rapidly. Each training point influences only nearby test points. The SVM essentially memorises each training point, creating a wildly oscillating boundary that perfectly separates training data but generalises poorly — classic high variance (overfitting).
Q8
The critical assumption enabling Gaussian NB computation
✅ B — Conditional independence: P(x|y=c) = Π P(xⱼ|y=c)
Without this assumption, computing P(x₁,...,x₁₁|y=AB) would require estimating an 11-dimensional joint Gaussian (66 covariance parameters per class vs 11 for NB). The independence assumption factorises this into 11 independent 1D Gaussians, requiring only 2 parameters (mean, variance) per feature per class = 22 params per class. This massive simplification enables fast training on small datasets.
Q9
Mathematical effect of 26.9× class weight on AB during training
✅ B — Each AB misclassification contributes 26.9× more to the loss gradient
L_weighted = Σᵢ wᵢ·L(f(xᵢ), yᵢ). The gradient for an AB sample is 26.9× larger than for a CI sample. Since gradient descent takes steps proportional to gradient magnitude, AB misclassifications drive parameter updates 26.9× harder than CI errors. The model converges to a solution that eliminates AB errors at the cost of tolerating more errors on less-penalised classes.
Q10
DT vs RF: 95.7%/91.8% train/test vs 99.2%/97.5% — bias-variance explanation
✅ B — Similar bias, RF has lower variance via bagging and feature subsampling
Both DT and RF can grow fully complex trees (low bias). The higher training accuracy of RF (99.2% vs 95.7%) is due to diversity: individual RF trees may overfit less-dominant features creating a richer collective boundary. But the key is test accuracy: RF's ensemble variance reduction produces 97.5% test accuracy vs DT's 91.8% — a 5.7% variance benefit from averaging 500 diverse trees.
Q11
Best SVM modification for asymmetric AB miss cost
✅ B — Class-weighted C: C_AB = 5× C_others
Class-weighted SVM inserts asymmetric slack penalty into the objective: min ½||w||² + Σ_c C_c·Σᵢ∈class_c ξᵢ. With C_AB=5C, the optimiser tolerates wide margins and errors on other classes to eliminate AB slack violations. Increasing C globally (Option A) would reduce all slack but doesn't specifically target the AB class, and forces a very narrow margin that may overfit. Class-weighting is the targeted, principled approach.
Q12
Why NB underperforms vs RF (AB Recall 79.3% vs 96.1%)
✅ B — Conditional independence violated: PRF, Speed, Doppler are correlated within AB class
For AB aircraft: high PRF (fire-control radar) occurs together with high speed and high Doppler shift — these three features are strongly positively correlated. NB computes P(PRF|AB)×P(Speed|AB)×P(Doppler|AB), multiplying as if independent. This underestimates the joint probability for the typical AB profile where all three are jointly high, leading to misclassifications at the AB/FF boundary where individual features overlap.
Q13
Operational meaning of FPR = 5% in IADS ROC analysis
✅ B — 5% of non-AB signals are incorrectly flagged as Adversary Bombers
FPR = FP/(FP+TN) = (non-AB signals falsely classified as AB) / (total non-AB signals). In IADS: non-AB includes FF, CM, UV, CI. At FPR=5%, 1 in 20 non-threat signals triggers an AB alert. Given IADS processes thousands of returns per minute, this generates a significant false alarm rate requiring human confirmation — but the RF achieves 97.8% TPR at this same 5% FPR threshold, making it a highly favourable trade-off.
Q14
Pruning 317→89 nodes: accuracy improves 91.8%→92.4%
✅ C — Pruning removes noise-fit subtrees, reducing variance for better generalisation
Deep trees develop highly specific decision paths (e.g., 'PRF between 1847-1849 Hz') that capture training noise rather than true signal. Cost-complexity pruning (with penalty α per leaf) removes subtrees where the accuracy gain on training data is less than the variance cost. The resulting tree is simpler (89 nodes vs 317) with slightly higher bias but much lower variance — the net effect improves test set accuracy by 0.6%.
Q15
OvR Logistic Regression probability calibration problem
✅ B — OvR probabilities don't sum to 1 across classes; calibration required
Each of the 5 binary LR models independently learns P(class_c | x) calibrated for its own binary problem (c vs all others). There is no joint constraint. For a given sample, Σ P̂(c|x) may equal 1.3 or 0.7 rather than exactly 1.0. To get valid class probabilities, apply normalisation: P(y=c|x) = P̂(c|x) / Σ_k P̂(k|x). Softmax-LR (multinomial) avoids this by construction: Softmax guarantees Σ P(c|x) = 1.

Assignment Q1 — Numerical [8 Marks]
A kNN classifier (k=3, Euclidean distance) is used on a 2-feature, 3-class dataset of radar contacts. Training data (Z-score normalised):

Pointx₁ (PRF norm.)x₂ (Speed norm.)Class
P10.20.8AB
P2−1.1−0.3FF
P30.91.4AB
P4−0.40.1FF
P51.80.6CM
P6−0.7−1.2FF
New query point: Q = (x₁=0.5, x₂=0.4).

(a) Compute the Euclidean distance from Q to each of the 6 training points. [3 marks]
(b) Identify the 3 nearest neighbours and classify Q (k=3, majority vote). [2 marks]
(c) If k=1 is used instead, what class does Q receive? [1 mark]
(d) Why is Z-score normalisation critical for this example? Which feature would dominate WITHOUT normalisation if PRF ranged from 500–3,000 Hz and Speed from 100–1,200 km/h? [2 marks]
Show Answer

(a) Euclidean Distances from Q=(0.5, 0.4):

$$ d(Q,P1) = √((0.5−0.2)² + (0.4−0.8)²) = √(0.09 + 0.16) = √0.25 = 0.500 d(Q,P2) = √((0.5−(−1.1))² + (0.4−(−0.3))²) = √(2.56 + 0.49) = √3.05 = 1.747 d(Q,P3) = √((0.5−0.9)² + (0.4−1.4)²) = √(0.16 + 1.00) = √1.16 = 1.077 d(Q,P4) = √((0.5−(−0.4))² + (0.4−0.1)²) = √(0.81 + 0.09) = √0.90 = 0.949 d(Q,P5) = √((0.5−1.8)² + (0.4−0.6)²) = √(1.69 + 0.04) = √1.73 = 1.315 d(Q,P6) = √((0.5−(−0.7))² + (0.4−(−1.2))²) = √(1.44 + 2.56) = √4.00 = 2.000 $$

(b) k=3 Nearest Neighbours and Classification:

$$ Ranked distances: P1=0.500 (AB) ← nearest P4=0.949 (FF) P3=1.077 (AB) P5=1.315 (CM) ← outside k=3 P2=1.747 (FF) P6=2.000 (FF) k=3 neighbours: P1(AB), P4(FF), P3(AB) Vote: AB=2, FF=1, CM=0 → Classify Q as: AB ✓ $$

(c) k=1 Classification:

$$ Nearest single neighbour: P1 at distance 0.500 → Class = AB (same result here) $$

(d) Why Z-score normalisation is critical:

$$ Without normalisation, raw PRF (500–3000 Hz) has range 2,500 Hz. Raw Speed (100–1200 km/h) has range 1,100 km/h. PRF dominates: a difference of 500 Hz in PRF contributes 500² = 250,000 to Euclidean distance², while a difference of 200 km/h in Speed contributes only 200² = 40,000 — 6.25× less influence! The classifier would effectively ignore Speed and cluster entirely on PRF magnitude — a systematically biased and unreliable result. Z-score makes both features have mean=0, std=1 → equal influence on distance. $$
Mark Scheme: (a) 0.5 mark per correct distance (6 distances = 3 marks). (b) 1 mark correct neighbours, 1 mark correct class. (c) 1 mark. (d) 1 mark for identifying PRF dominates, 1 mark for explanation of why.
Assignment Q2 — Mathematical Derivation [10 Marks]
A Decision Tree is being grown on a binary threat classification problem. At a given node, 400 samples remain: 280 are "THREAT" (T) and 120 are "NON-THREAT" (NT).

(a) Compute the Gini Impurity of this node. [2 marks]
(b) Two possible splits are proposed:
   Split A (on EW Jamming): Left=200 samples (180T, 20NT), Right=200 (100T, 100NT)
   Split B (on PRF > 2000): Left=150 samples (100T, 50NT), Right=250 (180T, 70NT)
Compute the Weighted Gini after each split and the Gini Reduction. Which split does CART choose? [5 marks]
(c) Using Entropy (Information Gain) instead of Gini, recompute which split is preferred. [3 marks]
Show Answer

(a) Gini of Parent Node:

$$ p_T = 280/400 = 0.70 p_NT = 120/400 = 0.30 Gini(parent) = 1 − (0.70² + 0.30²) = 1 − (0.49 + 0.09) = 1 − 0.58 = 0.420 $$

(b) Gini Reduction for Split A vs Split B:

$$ SPLIT A (EW Jamming): Left (200): p_T=180/200=0.90, p_NT=20/200=0.10 Gini_L = 1 − (0.81 + 0.01) = 0.180 Right (200): p_T=100/200=0.50, p_NT=100/200=0.50 Gini_R = 1 − (0.25 + 0.25) = 0.500 Weighted Gini_A = (200/400)×0.180 + (200/400)×0.500 = 0.090 + 0.250 = 0.340 Gini Reduction_A = 0.420 − 0.340 = 0.080 SPLIT B (PRF > 2000): Left (150): p_T=100/150=0.667, p_NT=50/150=0.333 Gini_L = 1 − (0.667² + 0.333²) = 1 − (0.445 + 0.111) = 0.444 Right (250): p_T=180/250=0.72, p_NT=70/250=0.28 Gini_R = 1 − (0.72² + 0.28²) = 1 − (0.518 + 0.078) = 0.403 Weighted Gini_B = (150/400)×0.444 + (250/400)×0.403 = 0.167 + 0.252 = 0.419 Gini Reduction_B = 0.420 − 0.419 = 0.001 → CART chooses SPLIT A (Gini Reduction 0.080 >> 0.001) $$

(c) Information Gain using Entropy:

$$ H(parent) = −0.70 log₂(0.70) − 0.30 log₂(0.30) = −0.70×(−0.515) − 0.30×(−1.737) = 0.3605 + 0.521 = 0.8816 SPLIT A — Entropy: H(Left): −0.90 log₂(0.90) − 0.10 log₂(0.10) = 0.137 + 0.332 = 0.469 H(Right): −0.50 log₂(0.50) − 0.50 log₂(0.50) = 0.500 + 0.500 = 1.000 IG_A = 0.8816 − [(0.5×0.469) + (0.5×1.000)] = 0.8816 − 0.7345 = 0.147 SPLIT B — Entropy: H(Left): −0.667 log₂(0.667) − 0.333 log₂(0.333) = 0.390 + 0.528 = 0.918 H(Right): −0.72 log₂(0.72) − 0.28 log₂(0.28) = 0.351 + 0.526 = 0.878 IG_B = 0.8816 − [(0.375×0.918) + (0.625×0.878)] = 0.8816 − (0.344+0.549) = 0.881−0.893 ≈ −0.012 → Entropy also selects SPLIT A (IG_A = 0.147 >> IG_B ≈ −0.012) $$
Both Gini and Information Gain agree: Split A (EW Jamming) is strongly preferred. The EW Jamming feature creates a nearly pure left branch (90% Threat) — a very informative split. Mark: (a) 2, (b) 5 (1 per Gini calc, 1 for conclusion), (c) 3 (1 per IG calc, 1 conclusion).
Assignment Q3 — SVM Derivation [10 Marks]
A binary SVM (Threat vs Non-Threat) is trained on a small dataset. After solving the dual, two support vectors are found: x₁ = [2, 3] (class y₁=+1) and x₂ = [−1, 1] (class y₂=−1) with α₁=0.5, α₂=0.5.

(a) Compute the weight vector w* = Σᵢ αᵢ yᵢ xᵢ. [2 marks]
(b) Compute the bias b* using the support vector condition y_i(w*·x_i + b) = 1 for both support vectors. [3 marks]
(c) For a new radar signal x_test = [1, 2], what is the classification? [2 marks]
(d) Compute the margin width = 2/||w*||. Explain why a wider margin is more robust in a noisy sensor environment. [3 marks]
Show Answer

(a) Weight vector w*:

$$ w* = Σᵢ αᵢ yᵢ xᵢ = α₁y₁x₁ + α₂y₂x₂ = 0.5×(+1)×[2,3] + 0.5×(−1)×[−1,1] = [1.0, 1.5] + [0.5, −0.5] = [1.5, 1.0] $$

(b) Bias b*:

$$ Using support vector x₁=[2,3], y₁=+1: y₁(w*·x₁ + b) = 1 (+1)([1.5,1.0]·[2,3] + b) = 1 (3.0 + 3.0 + b) = 1 6.0 + b = 1 → b = −5.0 Verification with x₂=[−1,1], y₂=−1: (−1)([1.5,1.0]·[−1,1] + (−5)) = 1 (−1)(−1.5 + 1.0 − 5.0) = 1 (−1)(−5.5) = 5.5 ≠ 1 Recalculate using average b from both SVs (correct method): From x₁: b = 1/y₁ − w*·x₁ = 1 − 6.0 = −5.0 From x₂: b = 1/y₂ − w*·x₂ = −1 − (−1.5+1.0) = −1−(−0.5) = −0.5 b* = (−5.0 + (−0.5)) / 2 = −2.75 [average for robustness] Note: This small dataset gives inconsistent results — in practice QP solvers enforce KKT conditions exactly. Use b*=−2.75. $$

(c) Classification of x_test=[1,2]:

$$ Decision: ŷ = sign(w*·x_test + b*) w*·x_test = [1.5,1.0]·[1,2] = 1.5 + 2.0 = 3.5 Score = 3.5 + (−2.75) = 0.75 > 0 ŷ = sign(0.75) = +1 → Classify as THREAT $$

(d) Margin Width and Noise Robustness:

$$ ||w*|| = √(1.5² + 1.0²) = √(2.25 + 1.0) = √3.25 = 1.803 Margin width = 2/||w*|| = 2/1.803 = 1.109 units Noise Robustness: A sensor measuring radar features has additive noise δx ~ N(0, σ_noise²). The margin represents the guaranteed correct classification zone. If a test point lies 0.8 margin-widths from the boundary, it will still be classified correctly even with noise perturbation up to 0.8×margin/2 = 0.4 units. A wider margin = larger safe zone around decision boundary = the classification is stable under sensor noise, measurement error, and slight adversary signature variations. This is WHY SVM's "maximum margin" criterion is not just mathematical elegance — it directly corresponds to real-world robustness in noisy defence sensors. $$
Mark Scheme: (a) 2 marks (1 per component). (b) 3 marks (1 per SV computation, 1 for average). (c) 2 marks (1 score, 1 classification). (d) 3 marks (1 ||w||, 1 margin width, 1 robustness explanation).
Assignment Q4 — Critical Analysis [12 Marks]
An IADS operator claims: "Our Random Forest achieved 97.5% accuracy on the test set. We trained it on our base's historical signal logs from 2018–2022 (balanced — 1,700 signals per class). We are deploying it to screen ALL air traffic in 2024, where 78% of signals are civilian."

(a) Identify THREE specific deployment risks in this scenario. [3 marks]
(b) Recompute the EXPECTED Adversary Bomber precision and recall in the 2024 deployment environment (real class distribution: CI=78%, FF=14%, UV=5%, CM=2%, AB=1%), assuming the confusion matrix from the balanced test set remains approximately valid. [6 marks]
(c) Propose TWO concrete technical mitigations. [3 marks]
Hint for (b): Per 100,000 signals, compute how many AB signals and non-AB signals there are. Of the AB signals, approximately 96.1% will be correctly identified (AB Recall from balanced evaluation). Of the non-AB signals, approximately 0.25% will be incorrectly flagged as AB (extrapolate from the confusion matrix). Use these to compute the operational Precision.
Show Answer

(a) Three Deployment Risks:

① Class Imbalance / Prior Shift: The model was trained and evaluated on a balanced dataset (equal 1,700 per class) but deployed with 78% Civilian and only 1% AB signals. The model's calibrated thresholds are set for equal-class priors. In the real distribution, the effective Precision for AB will collapse (many more civilians to generate false positives from).

② Temporal / Distribution Shift: Training data from 2018–2022 may not reflect 2024 aircraft technology, adversary EW doctrine changes, or new aircraft types entering service. A model trained on 2018-era radar signatures may fail to recognise 2024 adversary systems with updated electronic countermeasures.

③ Metric Misinterpretation: 97.5% test accuracy was on a balanced test set, giving an optimistic view. On the real distribution where AB is only 1%, even a model that classifies everything as non-AB achieves 99% accuracy — the baseline accuracy is already 99%! The relevant metric should have been AB Recall and Precision in the real operational distribution.

(b) Operational Precision & Recall (per 100,000 signals):

$$ Signal Distribution (100,000 signals): AB: 1,000 (1%) Non-AB: 99,000 (CI=78K, FF=14K, UV=5K, CM=2K) TRUE POSITIVES (AB correctly identified): AB Recall (from balanced eval) = 96.1% TP = 0.961 × 1,000 = 961 FALSE NEGATIVES (AB missed): FN = 1,000 − 961 = 39 ← 39 bombers MISSED per 100K signals! FALSE POSITIVES (non-AB flagged as AB): From balanced confusion matrix: overall false positive rate for AB ≈ (100-96.7)/100 ≈ 3.3% But this was in a balanced set. Estimated non-AB → AB false alarm ≈ 0.25% FP = 0.0025 × 99,000 = 247.5 ≈ 248 OPERATIONAL METRICS: $\text{Recall}=\frac{TP}{TP+FN}$ = 961/1000 = 96.1% [unchanged — intrinsic to model] $\text{Precision}=\frac{TP}{TP+FP}$ = 961/(961+248) = 961/1209 = 79.5% vs 97.4% Precision on balanced test set → Precision COLLAPSED from 97.4% → 79.5% due to class imbalance! → 20.5% of all AB alerts are FALSE alarms (247 per 100K signals) → This generates enormous alert fatigue for operators $$

(c) Technical Mitigations:

① Prior-adjusted threshold: Retrain the final decision layer using Bayes' theorem to adjust for the operational class prior P(AB)=0.01. Shift the AB classification threshold from 0.5 to approximately 0.15-0.20, accepting higher precision (fewer false alarms) at a small cost to recall. Alternatively, apply Platt scaling with the operational class distribution.

② Human-in-the-loop with staged confidence: Implement a two-tier system — RF flags "possible AB" above threshold θ₁=0.15 (high recall), then a human analyst or a higher-precision secondary model screens all flagged signals above θ₂=0.60. This reduces false alarms 10-fold while maintaining near-100% recall of actual threats. The 79.5% precision in tier 1 becomes >95% after human screening of the 1,209 alerts per 100K.

Key Insight: The Precision-Recall trade-off is ALWAYS evaluation-distribution dependent. A model evaluated on a balanced set gives optimistic Precision because the denominator (TP+FP) is inflated by the rare-class assumption. Always evaluate on a distribution matching operational deployment!
