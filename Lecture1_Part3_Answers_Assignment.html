Detailed Answer Explanations

Q1
Fundamental distinction between Supervised and Unsupervised Learning
✅ Correct Answer: B — Supervised requires labelled (x,y) pairs; Unsupervised finds structure in unlabelled {x}
The defining distinction is the presence of ground-truth labels. Supervised learning minimises a loss function L(f(x;θ), y) over labelled pairs. Unsupervised learning has no labels — it discovers inherent structure (clusters, densities, manifolds) in the data distribution P(x) alone. The architecture choice (neural network vs decision tree) and hardware are implementation details, not paradigm definitions.
Q2
Role of discount factor γ in RL wargame agent
✅ Correct Answer: C — γ balances immediate vs future rewards in G_t = Σ γ^k R_{t+k+1}
γ is not a learning rate (α) or exploration parameter (ε). In the return G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + …, γ≈1 means the agent values all future rewards equally (long-term strategic thinker). γ≈0 means the agent is myopic — maximises immediate reward only. In wargaming, γ≈0.95–0.99 is typical to balance short-term tactical gains with long-term campaign objectives.
Q3
Wald's aircraft armour analysis — which data pitfall?
✅ Correct Answer: C — Survivorship bias (only returning aircraft were observable)
The critical insight is that the analysis population was inherently biased — it consisted only of planes that survived. Planes destroyed by hits to engines or cockpits were absent from the analysis by definition. This is survivorship bias: the failure mode is invisible because failures don't return to be counted. In ML: any training dataset built from "successful outcomes" or "surviving entities" carries this same structural bias.
Q4
Why is 97.2% accuracy insufficient for radar threat classification?
✅ Correct Answer: C — Asymmetric costs: false negatives (missed threats) have catastrophically higher operational cost than false positives
Accuracy = (TP+TN)/(TP+TN+FP+FN) treats all errors equally. In IADS, a false negative (enemy bomber classified as 'Friendly') = catastrophic operational failure. A false positive (civilian classified as 'threat' = unnecessary alert) is costly but recoverable. The appropriate metric is Recall_threat = TP/(TP+FN), optimised within an acceptable Precision constraint. F1 partially addresses this but the real solution is asymmetric cost-weighted loss functions during training.
Q5
Silhouette Score of 0.683 for OPFOR movement clustering
✅ Correct Answer: C — Moderate-to-good cluster structure; some overlap, particularly ASSAULT/TRANSIT
Silhouette s = (b-a)/max(a,b) where a = avg intra-cluster distance, b = avg distance to nearest other cluster. Range: [-1, +1]. Score 0.683 > 0.5 (reasonable) but < 0.7 (strong). It does NOT represent classification accuracy (68.3%) — that interpretation conflates the metric with its meaning. It tells analysts that cluster boundaries exist but with some overlap, requiring additional validation before operational deployment.
Q6
Best architecture for time-series sensor track classification
✅ Correct Answer: B — RNN/LSTM: designed for sequential temporal dependencies
LSTM explicitly models temporal state through gated memory cells (input, forget, output gates), allowing it to capture dependencies across time steps — critical for trajectory analysis where movement at t=5 depends on t=1 through t=4. While 1D-CNN (Option A) can also work on time series by treating time as a spatial dimension, LSTM is the better-motivated choice for movement trajectories where long-range temporal dependencies matter. GAN (C) is generative, not discriminative. PCA+GMM (D) is unsupervised.
Q7
Primary mechanism behind RAG's accuracy improvement
✅ Correct Answer: C — Retrieved context injected into prompt grounds generation in verified source material
RAG architecture: Query → Embed → Vector search → Retrieve top-k chunks → Augment prompt with [Query + Context] → LLM generates conditioned on both. The LLM isn't changed — it's the same model. The improvement comes from replacing hallucination-prone parametric memory with verified retrieved content. RAG doesn't eliminate hallucination (3.2% still occurs), and it adds latency (+1.3s). Option D is incorrect: RAG still uses an LLM for generation.
Q8
Which scenario represents Simpson's Paradox in wargame data?
✅ Correct Answer: C — AI units better in BOTH terrain types, but appear equal in aggregate due to non-AI unit bias toward easier terrain
Simpson's Paradox: A effect appears in each sub-group but disappears or reverses when groups are combined. The confounder (terrain difficulty) is unevenly distributed between groups — non-AI units are over-represented in easier terrain, inflating their apparent aggregate performance. This is a classic confounding problem in observational data and a common trap in wargame exercise analysis. Option A is simulation-to-reality gap; Option D is overfitting.
Q9
Mine detection model fails from Afghan to Iraqi terrain — primary cause?
✅ Correct Answer: C — Covariate (distribution) shift: P_train(x) ≠ P_deploy(x)
Training accuracy 97.3% → high model capacity and sufficient data. Test accuracy in same terrain 94.1% → no significant overfitting in Afghan domain. Test accuracy in Iraqi terrain 58.7% → catastrophic generalisation failure due to input distribution mismatch (soil composition, moisture, texture, electromagnetic properties differ between terrains). This is covariate shift, not label noise (labels were accurate), not selection bias (training was representative of Afghan terrain), and not underfitting (training accuracy was high).
Q10
Catering quality vs win rate correlation drops to r=0.09 after controlling for budget
✅ Correct Answer: B — Spurious correlation: unit budget is the confounding variable
The partial correlation technique isolates the direct relationship between two variables by statistically removing the effect of a third (confounder). Here, r_partial(catering, win | budget) = 0.09 (p=0.42 — not significant). This shows the original r=0.71 was entirely explained by budget driving both. If we train an ML model on catering quality to predict win rate without controlling for budget, the model will learn this spurious association and give misleading predictions in new exercises with different budget distributions.
Q11
Why does SSL pre-training + fine-tuning outperform from-scratch with same 1,000 labels?
✅ Correct Answer: C — SSL learns transferable feature representations through pretext tasks on 500K unlabelled samples
SSL (self-supervised learning) trains a model to solve a pretext task (e.g., predict masked signal portions) on large unlabelled data. This forces the model to learn semantically rich, generalisable representations. When fine-tuned with only 1,000 labelled examples, the pre-trained feature extractor provides a much better starting point than random initialisation, requiring fewer labels to reach high accuracy. Options A and B are factually incorrect about the mechanism. Option D is factually wrong: SSL uses NO labels during pre-training.
Q12
Interpretation of a large positive TD error in Q-Learning
✅ Correct Answer: B — Current Q-value is an underestimate; agent performed better than expected → increase Q(s,a)
TD error δ = r + γ max_{a'} Q(s',a') − Q(s,a). Large positive δ means the target [r + γ max Q(s',a')] exceeds the current estimate Q(s,a). The agent received more cumulative value from this action than it predicted → the current Q-value underestimates the true value. The update Q(s,a) ← Q(s,a) + α·δ increases Q(s,a) toward the target. A large negative δ would indicate overestimation, requiring a downward correction.
Q13
Most dangerous form of data poisoning in defence AI
✅ Correct Answer: B — Targeted backdoor: inject mislabelled samples to cause specific controlled misclassifications
Targeted (backdoor) poisoning is far more dangerous than random noise addition because: (1) it creates a specific, controllable misclassification on demand, (2) it can be triggered by a specific input pattern the adversary controls, (3) overall model accuracy remains near-normal (making detection difficult), and (4) the effect persists after model deployment. At 3% poisoning rate, 94% of target class samples can be flipped — e.g., an adversary's specific aircraft signature always classified as 'Friendly' by our IADS.
Q14
Core advantage of Transformer self-attention over RNNs for long intelligence reports
✅ Correct Answer: C — Direct O(n²) attention between any positions resolves RNN vanishing gradient problem
Attention(Q,K,V) = softmax(QK^T/√d_k)·V computes pairwise relationships between ALL token positions in a single matrix operation. A relationship between token 1 and token 500 in a report is computed with the same weight as token 499 to 500. RNNs process sequentially: to connect token 1 to token 500, information must flow through 499 timesteps with multiplicative gradient updates — leading to vanishing (or exploding) gradients. Long documents cause RNNs to 'forget' early context, while Transformers have no such distance limitation.
Q15
CGF AI agent: 91% win rate in simulation → 58% in field exercise
✅ Correct Answer: C — Simulation-to-reality gap: unrealistic physics exploitation + distribution shift from fog-of-war and adversarial adaptation
The sim-to-real gap is the most important practical challenge for RL wargame agents. Three compounding factors: (1) Simulation physics exploitation: RL agents often exploit bugs or simplifications in simulation models that don't correspond to real-world behaviour. (2) Covariate shift: Real-world input distributions (terrain friction, comms degradation, weather, fatigue) differ from simulation inputs. (3) Adversarial non-stationarity: Human opponents in field exercises adapt, unlike static scripted environments. The specific RL algorithm used (Q-Learning vs PPO) rarely accounts for this magnitude of gap.

Assignment Q3 — Conceptual [5 Marks]
A defence analyst notices that in wargame exercise data from the past 3 years, units from Brigade X consistently outperform Brigade Y across all terrain types (urban: 87% vs 72%, desert: 91% vs 79%, jungle: 83% vs 68%). However, when the data is combined, Brigade X's overall win rate is only 0.5% higher than Brigade Y's overall win rate.

(a) What statistical phenomenon does this represent? [1 mark]
(b) Identify the most likely confounding variable that could explain this paradox in a military exercise context. [2 marks]
(c) If an ML model is trained on the combined data without controlling for this confounder, what erroneous conclusion might the model's feature importance output suggest? And why is this dangerous for operational planning? [2 marks]
Show Answer

(a) Statistical Phenomenon: Simpson's Paradox — a trend appears consistently in subgroups but reverses or disappears in the combined aggregate analysis.


(b) Most Likely Confounder: Mission/terrain assignment distribution. Brigade Y has likely been assigned to disproportionately EASIER exercises or terrain types (e.g., open desert, lower threat density), while Brigade X was assigned to harder operational environments. When all exercises are combined, the easier missions inflate Brigade Y's aggregate win rate to near parity with Brigade X, despite Brigade X performing better in every specific terrain category. Alternative valid answers: opponent quality differences, exercise timing (fatigue), weather conditions.


(c) Erroneous ML Conclusion & Operational Danger: The ML model's feature importance output might show that Brigade X's unit identifier or equipment type has near-zero importance (since the combined win rate difference is only 0.5%), suggesting that Brigade X's training/doctrine/equipment provides no operational advantage. An operational planner relying on this could: (1) allocate resources uniformly between brigades despite Brigade X's demonstrable superiority in all terrain types, (2) deny Brigade X additional resources believing the advantage is negligible, (3) assign Brigade X to simpler missions "since it wins at about the same rate." All of these are wrong decisions caused by Simpson's Paradox in the training data.

Key Lesson: Always analyse data within relevant subgroups before combining. In defence ML, aggregate performance metrics can hide systematic advantages or disadvantages that are only visible in disaggregated analysis.
Assignment Q4 — Mathematical Derivation [10 Marks]
A RL agent is being trained for a tactical wargame using Q-Learning. The current Q-table has the following values for state s1:

ActionQ(s1, a)
Move North (a1)12.4
Attack (a2)18.7
Defend (a3)9.2
Resupply (a4)6.1

The agent takes action a2 (Attack) from state s1. It receives reward r = +10 (objective captured) and transitions to state s2. The Q-values for state s2 are: Q(s2, a1) = 22.3, Q(s2, a2) = 15.6, Q(s2, a3) = 19.8, Q(s2, a4) = 8.4.

Parameters: Learning rate α = 0.15, Discount factor γ = 0.90.

(a) Using the Q-Learning update rule, calculate the TD error (temporal difference error). [3 marks]
(b) Calculate the updated Q(s1, a2) after this one experience. [2 marks]
(c) If the agent uses an ε-greedy policy with ε = 0.1, what is the probability that it chooses action a2 (Attack) in state s1 BEFORE this update? [2 marks]
(d) After 100 more experiences from state s1 all showing attack is optimal, the TD errors converge to ≈ 0. What does this indicate about convergence, and what is the approximate new Q(s1, a2) assuming the Bellman equation is satisfied? [3 marks]
Show Answer

(a) TD Error Calculation:

Q-Learning update: Q(s,a) ← Q(s,a) + α[r + γ·max_{a'} Q(s',a') − Q(s,a)]

max_{a'} Q(s2, a') = max(22.3, 15.6, 19.8, 8.4) = 22.3 (action a1 in s2)

TD Target = r + γ · max Q(s2,·) = 10 + 0.90 × 22.3 = 10 + 20.07 = 30.07

TD Error δ = TD Target − Q(s1, a2) = 30.07 − 18.7 = 11.37

(b) Updated Q(s1, a2):

Q(s1, a2)_new = Q(s1, a2)_old + α × δ
= 18.7 + 0.15 × 11.37
= 18.7 + 1.706
= 20.406

(c) ε-greedy Action Selection Probability:

In state s1, Q(s1, a2) = 18.7 is the HIGHEST Q-value (18.7 > 12.4 > 9.2 > 6.1).
a2 is the greedy (optimal) action.

P(select a2) = P(exploit) × P(a2 | exploit) + P(explore) × P(a2 | explore)
= (1-ε) × 1 + ε × (1/4)
= (0.90) × 1 + (0.10) × 0.25
= 0.90 + 0.025 = 0.925 (92.5%)

(d) Convergence Analysis:

TD error → 0 means: r + γ · max Q(s',a') ≈ Q(s,a)
This is the Bellman optimality condition — Q* satisfies it exactly.

When satisfied: Q*(s1, a2) = r + γ · max_{a'} Q*(s2, a')

Assuming max Q*(s2,·) ≈ 22.3 (still approximately valid after convergence):
Q*(s1, a2) ≈ 10 + 0.90 × 22.3 = 30.07

(The value increased from 18.7 → ~30.07, reflecting the true long-term value
of capturing objectives from this state with γ-discounted future rewards.)
Convergence (TD error ≈ 0) guarantees Q-table represents the true optimal value function Q*. In practice, DQN achieves this approximately after 50,000–100,000 episodes in complex wargame environments.
Assignment Q5 — Critical Analysis [10 Marks]
A research paper claims: "Our AI-powered ammunition demand forecasting system achieved 96.3% accuracy when tested on 2021 data, validating its readiness for deployment in the 2024 campaign." The system was trained on Indian Army logistics data from 2015–2020.

(a) Identify FOUR distinct data pitfalls or validity concerns with this evaluation and claim. [4 marks]
(b) For EACH pitfall, describe one specific example of how it could manifest in this ammunition forecasting context. [4 marks]
(c) Propose two improvements to the evaluation methodology that would provide stronger evidence of deployment readiness. [2 marks]
Show Answer

(a) & (b) Four Pitfalls with Examples:

① Temporal Distribution Shift (train: 2015–2020, test: 2021):
The model is trained and tested on data from the SAME strategic period. The claim "ready for 2024" requires testing on 2022–2024 data, which likely reflects different geopolitical context, updated weapon systems, changed logistics doctrine, inflation effects on resource consumption, and potential new conflict types. A model trained on peacetime consumption patterns (2015–2020) may fail catastrophically if 2024 involves active operations with radically different consumption rates.

② Survivorship Bias / Selection Bias in Training Data:
Training data from 2015–2020 likely represents "normal operations" — the system worked as intended. High-consumption outlier events (exercises, border escalations, equipment failures causing resupply spikes) may be under-represented or excluded as "anomalies" during data cleaning. The model won't predict these rare but critical high-demand events accurately.

③ Overfitting to Seasonal/Peacetime Patterns:
Ammunition consumption has seasonal patterns (winter exercises, summer border activity). A model that achieves 96.3% on 2021 data may be overfitting to these patterns rather than learning genuine demand drivers. If 2024 operations don't follow the same seasonal calendar (e.g., operations during monsoon), the model fails.

④ P-Hacking / Metric Selection Bias:
96.3% accuracy is an overall metric. Ammunition forecasting errors are not symmetric — underestimating demand (shortage) is operationally catastrophic while overestimating (excess stock) is merely costly. If the model achieves 96.3% accuracy but has 40% error rates on high-consumption spikes (rare but critical), the headline accuracy is misleading. The paper likely selected accuracy (a metric that looks good) rather than reporting separate metrics for high-demand event prediction.

(c) Improved Evaluation Methodology:

Improvement 1: Walk-forward validation across time — train on 2015–2018, test on 2019; train on 2015–2019, test on 2020; train on 2015–2020, test on 2021–2022. This tests generalisability across time and reveals performance degradation trends. Include separate metrics for high-demand event recall.

Improvement 2: Out-of-distribution (OOD) robustness testing — deliberately test on data from fundamentally different operational scenarios (high-intensity operations, equipment changeover, new weapon system introduction). Also calculate prediction uncertainty intervals and evaluate calibration: does "90% confident" correspond to 90% actual accuracy?

Core Lesson: A single test accuracy number on in-distribution data tells you very little about deployment readiness. Operational AI systems require multi-temporal validation, cost-asymmetric metrics, OOD testing, and uncertainty quantification before deployment claims are valid.
