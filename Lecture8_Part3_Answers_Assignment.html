Selected Explanations

Q3
How does QMIX monotonicity enable decentralised greedy execution?
✅ B — $\partial Q_{\text{tot}}/\partial Q_i>0$ → increasing any Qᵢ increases Q_tot → joint argmax = individual argmax
Proof: Suppose joint action a* = (a₁*,...,aN*) maximises Q_tot. For any agent i, if aᵢ ≠ argmax_{aᵢ} Qᵢ(aᵢ), then there exists aᵢ' with Qᵢ(aᵢ') > Qᵢ(aᵢ). By monotonicity, Q_tot with (aᵢ', a_{-i}*) > Q_tot with (aᵢ, a_{-i}*). This contradicts a* being the joint optimum. Therefore a* must have aᵢ* = argmax Qᵢ for all i. Each agent can independently take its greedy action. This is the Individual-Global-Max (IGM) property — the bridge between centralised training and decentralised execution.
Q8
COMA counterfactual advantage A₃ = −3.2 for Artillery that missed
✅ B — A₃ = Q(s,a_actual) − b₃ = −3.2 means actual action was 3.2 units WORSE than agent 3's policy average
b₃(s,a_{-3}) = Σ_{a₃'} π₃(a₃'|o₃) Q(s,(a₃',a_{-3})): the average Q-value across all of Agent 3's possible actions (weighted by policy probability) while others hold their actions fixed. A₃ = −3.2 means 'fire early' was 3.2 worse than this average. Policy gradient: reduces P(fire_early|o₃ in this state). This is exactly the right signal: the specific action chosen was worse than the agent's baseline — it should be made less probable. Naive sharing would give Agent 3 +16.7 (positive!) → wrongly reinforcing the early firing behaviour.
Q10
How does MAPPO's centralised critic enable the flanking tactic to emerge?
✅ B — V(s) captures joint configuration value; flanking configuration has high V(s') → PPO updates both agents toward it
The flanking manoeuvre requires TWO agents to coordinate: Infantry → frontal position, Armour → flank position, SIMULTANEOUSLY. IQL: Agent 1's Q₁(o₁,advance_frontal) doesn't know where Agent 2 is — it can't distinguish flanking from non-flanking. MAPPO's V(s) where s includes both agents' positions: V(s_flanking) >> V(s_all_frontal) because flanking configurations (empirically, through training) lead to much better mission outcomes. When both agents happen to create this joint configuration (via exploration), V(s') is high → high advantage for BOTH agents → PPO reinforces both actions simultaneously. This is joint credit flowing through a single centralised value function.

Q1 — QMIX Value Decomposition [10 Marks]
A 3-agent QMIX system has individual Q-values: Q₁(a₁=ATTACK)=8.0, Q₂(a₂=FLANK)=6.0, Q₃(a₃=SUPPRESS)=5.0. The QMIX mixer (simplified 1-layer) uses: Q_tot = w₁Q₁ + w₂Q₂ + w₃Q₃ + b where weights from the hypernetwork are: w₁=0.4, w₂=0.3, w₃=0.3, b=1.0.

(a) Compute Q_tot for the joint action (ATTACK, FLANK, SUPPRESS). [2 marks]
(b) Agent 2 considers switching to DEFEND (Q₂(DEFEND)=3.5). Compute new Q_tot and verify the monotonicity property holds. [3 marks]
(c) The TD target is y = r + γ max_{a'} Q_tot(s'): the next state has best per-agent Q-values Q₁'=7.0, Q₂'=5.5, Q₃'=6.0 with the same mixer weights, r=+10, γ=0.9. Compute y and the QMIX loss for the current transition. [3 marks]
(d) The loss backpropagates to update w₁. Compute ∂Q_tot/∂w₁ and state the direction of the gradient update. [2 marks]
Show Answer

(a) Q_tot for (ATTACK, FLANK, SUPPRESS):

$$ Q_tot = w₁Q₁ + w₂Q₂ + w₃Q₃ + b = 0.4×8.0 + 0.3×6.0 + 0.3×5.0 + 1.0 = 3.2 + 1.8 + 1.5 + 1.0 = 7.5 $$

(b) Agent 2 switches to DEFEND (Q₂=3.5):

$$ Q_tot_new = 0.4×8.0 + 0.3×3.5 + 0.3×5.0 + 1.0 = 3.2 + 1.05 + 1.5 + 1.0 = 6.75 Monotonicity verification: Q₂(FLANK) = 6.0 > Q₂(DEFEND) = 3.5 → Q₂ decreased Q_tot_original = 7.5 > Q_tot_new = 6.75 → Q_tot decreased ✓ ∂Q_tot/∂Q₂ = w₂ = 0.3 > 0 (positive weight = monotonic!) ✓ QMIX monotonicity confirmed: decreasing any Qᵢ decreases Q_tot (and vice versa), because all wᵢ > 0. DECENTRALISED EXECUTION CHECK: Agent 2 independently: argmax_a Q₂(a) = FLANK (6.0 > 3.5) ✓ Joint argmax Q_tot: achieved by each agent greedily = (ATTACK, FLANK, SUPPRESS) ✓ No coordination needed at execution time! $$

(c) TD target and QMIX loss:

$$ Q_tot(s', best joint action): Best per-agent Q-values in s': Q₁'=7.0, Q₂'=5.5, Q₃'=6.0 Q_tot(s') = 0.4×7.0 + 0.3×5.5 + 0.3×6.0 + 1.0 = 2.8 + 1.65 + 1.8 + 1.0 = 7.25 TD Target: y = r + γ Q_tot(s') = 10 + 0.9 × 7.25 = 10 + 6.525 = 16.525 QMIX Loss (TD error squared): δ = y − Q_tot(s,a) = 16.525 − 7.5 = 9.025 L = δ² = (9.025)² = 81.45 Large positive TD error (δ=9.025) means current Q_tot severely underestimates the true value of this state-action pair. Gradient will INCREASE Q_tot → increase all wᵢ and Q-network weights. $$

(d) Gradient ∂Q_tot/∂w₁ and update direction:

$$ ∂Q_tot/∂w₁ = Q₁(a₁) = 8.0 [chain rule through Q_tot = w₁Q₁+...] Loss gradient: ∂L/∂w₁ = ∂L/∂Q_tot × ∂Q_tot/∂w₁ = −2δ × Q₁ = −2 × 9.025 × 8.0 = −144.4 Gradient descent update: w₁ ← w₁ − η × (−144.4) = w₁ + 144.4η Direction: w₁ INCREASES (positive update). Since δ > 0 (Q_tot underestimates), the loss gradient pushes w₁ UPWARD → Q_tot increases → closer to target y. The hypernetwork weights will be updated to increase the contribution of Q₁=8.0 (ATTACK) to Q_tot. $$
Mark Scheme: (a) 2 marks. (b) 3 marks (new Q_tot 1, monotonicity check 1, decentralised execution verification 1). (c) 3 marks (Q_tot(s') 1, TD target 1, loss 1). (d) 2 marks (gradient formula 1, direction 1).
Q2 — CTDE Credit Assignment Analysis [10 Marks]
A 4-agent MAPPO team executes a mission: Infantry (A1), Armour (A2), Drone (A3), Artillery (A4). The mission succeeds (+100). Individual COMA counterfactual advantages measured: A₁=+12.4, A₂=+8.6, A₃=−2.1, A₄=+14.8.

(a) Interpret each agent's counterfactual advantage in operational terms. Which agent performed worst relative to its policy average? [3 marks]
(b) Verify that the sum of advantages ≈ 0 is NOT guaranteed for COMA (unlike some other formulations). Compute Σ Aᵢ and explain what this sum represents. [3 marks]
(c) Based on these advantages, write the MAPPO policy gradient update direction for each agent (increase/decrease which actions?). If Agent 3 (Drone) took action ISR_PASSIVE, what does A₃=−2.1 tell a mission planner? [4 marks]
Show Answer

(a) Operational interpretation of counterfactual advantages:

$$ Recall: A_i = Q(s, a_joint) − b_i(s, a_{-i}) where b_i = E_{a_i~π_i}[Q(s,(a_i, a_{-i}))] A₁ (Infantry) = +12.4: Infantry's ACTUAL action was 12.4 reward units BETTER than its average policy action in this state. Infantry performed WELL — its specific action (e.g., frontal advance under cover) was significantly more valuable than its average action would have been. Policy update: INCREASE probability of this action in similar states. A₂ (Armour) = +8.6: Armour's action was 8.6 units better than its average. Also a positive contributor, though less so than Infantry. Policy update: INCREASE probability of this action. A₃ (Drone) = −2.1: Drone's ISR_PASSIVE action was 2.1 units WORSE than its average action would have been. The drone underperformed — its passive ISR was less valuable in this state than its average action. Policy update: DECREASE probability of ISR_PASSIVE in similar states. A₄ (Artillery) = +14.8: Artillery contributed most — its action (well-timed suppressive fire) was 14.8 units better than its average. WORST PERFORMER: Agent 3 (Drone) with A₃ = −2.1 (only negative advantage) $$

(b) Sum of advantages and interpretation:

Σ Aᵢ = A₁ + A₂ + A₃ + A₄ = 12.4 + 8.6 + (−2.1) + 14.8 = 33.7 This is NOT zero (unlike, e.g., reward minus baseline formulations). WHY Σ Aᵢ ≠ 0 IN COMA: Each A_i uses a DIFFERENT baseline b_i — Agent 1's baseline fixes all other agents and marginalises over Agent 1's actions; Agent 2's baseline fixes all other agents and marginalises over Agent 2. These are different marginalisation operations, so the sum has no theoretical guarantee of being zero. WHAT Σ Aᵢ = 33.7 REPRESENTS: This is roughly the total "above-average" contribution of this specific joint action combination relative to each agent's independent average. It is NOT the total advantage above a global team baseline. Compare with total team reward = 100 (mission success): Σ Aᵢ = 33.7 << 100 → makes sense: each counterfactual only measures the MARGINAL contribution of each agent's specific action, not the total reward. The 100 includes contributions from the environment, team synergies, and the baseline performance.

(c) Policy gradient updates and Drone mission implication:

$$ MAPPO POLICY GRADIENT (each agent): θ ← θ + α × Aᵢ × ∇_θ log π_θ(aᵢ|oᵢ) Agent 1 (Infantry): A₁=+12.4 → INCREASE P(frontal_advance|state) Gradient pushes θ toward taking Infantry's specific action more in states similar to the current state. Agent 2 (Armour): A₂=+8.6 → INCREASE P(flank_left|state) [or whichever action] Moderate positive update. Agent 3 (Drone): A₃=−2.1 → DECREASE P(ISR_PASSIVE|state) Gradient pushes θ AWAY from ISR_PASSIVE in this type of state. The drone should have taken a more active action. Agent 4 (Artillery): A₄=+14.8 → INCREASE P(suppressive_fire|state) Strongest positive update — well-timed artillery was the biggest contributor in this mission phase. MISSION PLANNER INTERPRETATION OF A₃=−2.1: The Drone chose ISR_PASSIVE (passive monitoring) in a state where: - Artillery was about to fire (needs targeting data from active ISR) - Infantry was advancing into a blind spot The COMA advantage quantifies: ACTIVE ISR in this state would have been worth +2.1 more to the team than passive ISR. OPERATIONAL RECOMMENDATION: Update doctrine for this engagement phase — drones should switch from passive to active ISR when artillery is preparing to fire AND infantry is in a tactical advance. The MARL signal validates a doctrinal gap: active coordination of ISR timing with fires and manoeuvre is sub-optimally handled. TRAINING FIX: Add intermediate reward r_isi_timing = +2 when drone provides active targeting data within 2 turns of an artillery fire mission. $$
Mark Scheme: (a) 3 marks (1 per agent interpretation, worst performer identified). (b) 3 marks (sum computed 1, why not zero 1, interpretation of 33.7 1). (c) 4 marks (gradient direction per agent 2, Drone operational interpretation 1, training fix recommendation 1).
Q3 — Emergent Communication Design [10 Marks]
(a) CommsMAPPO added an 8-dimensional continuous message channel per agent. Design the TRAINING architecture: specify the input to each agent's actor, how gradients flow through the communication channel to the message encoder, and why this is differentiable end-to-end. [4 marks]

(b) After training, the messages are analysed. Linear probing for 'SAM_ACTIVE' (binary, 1=SAM still operational) achieves 91.4% accuracy from message m[3-5]. What does 91.4% accuracy mean statistically, and what does it NOT prove about the communication? [3 marks]

(c) An adversary captures one of the drones and reverse-engineers the communication protocol, learning the encoding m[0-2] = enemy position, m[3-5] = SAM status. They then inject false messages claiming 'SAM neutralised' (m[3-5] = all zeros). Model the impact on the team's mission success and propose a cryptographic countermeasure compatible with the MARL architecture. [3 marks]
Show Answer

(a) CommsMAPPO training architecture and gradient flow:

$$ AGENT i ARCHITECTURE (with communication): Step 1 — MESSAGE ENCODING: Agent i observes oᵢ → Message encoder: mᵢ = f_enc(oᵢ; θ_enc) Output: mᵢ ∈ ℝ⁸ (8-dimensional continuous message) Same encoder shared across agents (parameter sharing) Step 2 — MESSAGE EXCHANGE: Agent i receives messages from all other N-1 agents: {m₁,...,m_{i-1},m_{i+1},...,mN} (At training time: no bandwidth constraint; all messages available) (At execution: broadcast over tactical datalink) Step 3 — ACTOR COMPUTATION: Augmented observation: [oᵢ, m₁,...,m_{i-1},m_{i+1},...,mN] Total input: 80-dim obs + 7×8 = 80+56 = 136-dim Actor: π_θ(aᵢ | oᵢ, {m_j}_{j≠i}) Output: action distribution over 7 actions GRADIENT FLOW (why differentiable end-to-end): Loss L depends on aᵢ → depends on actor output → depends on {m_j} inputs → depends on f_enc(o_j; θ_enc) Since f_enc is a neural network (e.g., 2-layer MLP with ReLU), and the message mⱼ is a continuous vector (not discrete), the full computation graph is differentiable: ∂L/∂θ_enc_j = (∂L/∂aᵢ)(∂aᵢ/∂mⱼ)(∂mⱼ/∂θ_enc_j) The encoder LEARNS what to communicate by receiving gradient signal from how its messages affect OTHER agents' actions and the resulting team reward. No explicit "encode enemy position" reward needed — the encoder learns to encode tactically useful information because doing so improves L (the PPO objective). $$

(b) Statistical meaning of 91.4% probing accuracy:

$$ WHAT 91.4% MEANS: A LINEAR classifier trained on m[3-5] (3 numbers from the message) correctly predicts SAM_ACTIVE (binary: 0/1) in 91.4% of test cases. Baseline (random/majority class): if SAM is active 60% of the time, a majority-class classifier achieves 60% — the 91.4% is far above chance. This confirms: SAM_ACTIVE information IS LINEARLY ENCODED in m[3-5] — i.e., there exists a linear combination w·m[3-5] + b that predicts SAM_ACTIVE with 91.4% accuracy. WHAT IT DOES NOT PROVE: ① It does not prove agents INTENTIONALLY communicate SAM status. The encoding may be a byproduct of other information being communicated — SAM status correlates with other things that the agent IS intentionally communicating. ② It does not prove other agents USE the SAM status information. Receiving agents might decode the message through nonlinear operations, using information orthogonal to the SAM signal. ③ It does not prove 91.4% of the message is about SAM status — it shows SAM status is recoverable from only 3 dimensions of the 8-dimensional message (the other 5 may carry other info). ④ Correlation ≠ causation: m[3-5] may correlate with SAM status without being the REASON those message dimensions are used. $$

(c) Message spoofing attack and cryptographic countermeasure:

$$ SPOOFING ATTACK IMPACT: If adversary injects m[3-5] = [0,0,0] (false "SAM neutralised"): Ground units' actors receive: "SAM down" → advance without air cover SEAD aircraft: "SAM down" → deprioritises SEAD mission RESULT: Ground units advance under active SAM fire Expected casualties: avg 1.2 → ~3.4+ units (SAM engages drones/armour) Mission success: 82.4% → ~51% estimated (based on SAM-active episode data) This is a mission-critical vulnerability! CRYPTOGRAPHIC COUNTERMEASURE (MARL-compatible): Option 1: AUTHENTICATED MESSAGE SIGNING Each agent signs its message with a symmetric key shared at mission briefing: m_signed = (mᵢ, HMAC(mᵢ, K_shared)) Receiving agents verify HMAC before using message. Spoofed messages (without K_shared) fail verification → rejected. MARL impact: None — the architecture remains unchanged; messages include authentication tag as extra dimensions. Option 2: CHALLENGE-RESPONSE IN SHARED MEMORY Train MARL with a 'trust score' per message source: If agent j's messages consistently predict correct outcomes (cross-referenced against own observation when observable): trust_j increases; if inconsistent: trust_j decreases. Spoofed messages from adversary will rapidly accumulate prediction errors → trust_spoofed → 0 → messages ignored. More complex to implement but requires no pre-shared key. RECOMMENDED: Option 1 for rapid deployment (compatible with existing MARL policy; adds authentication layer at message interface level). $$
Mark Scheme: (a) 4 marks (input spec 1, gradient flow through comm channel 2, why differentiable 1). (b) 3 marks (what 91.4% means 1.5, what it doesn't prove 1.5). (c) 3 marks (attack impact quantified 1, countermeasure mechanism 1, MARL compatibility 1).
Q4 — MARL Design for a New Scenario [10 Marks]
A naval task force has 1 frigate, 2 helicopters, and 1 submarine. The mission is to intercept an adversary convoy (5 vessels) in an area with 2 adversary patrol aircraft. Design a complete MARL system for this task.

(a) Define the Dec-POMDP components: state S, observation per agent Ωᵢ, action space Aᵢ for each platform, reward function r(s,a), and discount factor γ with justification. [5 marks]
(b) Select between QMIX and MAPPO for this scenario and justify. Consider: action space type, coordination complexity, and communication constraints at sea. [3 marks]
(c) Identify TWO specific emergent behaviours you would EXPECT from a well-trained MARL agent in this scenario (based on the combined arms lessons), and describe what reward chain would drive each. [2 marks]
Show Answer

(a) Dec-POMDP components:

$$ STATE S (global, used only at training time): - All 4 friendly platform positions (x,y) + headings + fuel/ammo states - All 5 convoy positions + estimated speeds + cargo classifications - 2 adversary patrol aircraft positions + threat status - Environmental: sea state (0-9), visibility, wind (speed + direction) - Area control: engagement zones, ROE state Total state dimension: ~85 features OBSERVATION PER AGENT Ωᵢ (partial, at execution): FRIGATE: Radar range 200nm. Sees all vessels within range. oᵢ: [own pos/heading/speed, nearby contacts (up to 12 × 6 features), helicopter positions (if within 50nm), sea state, ammo state] ~85-dim HELICOPTER: Sonar/radar range 50nm. Sees surface and subsurface. oᵢ: [own pos/heading/fuel, surface contacts (up to 6 × 6), sonar contacts (up to 3 × 4), frigate position/bearing] ~70-dim SUBMARINE: Sonar only, no radar. Range 40nm. No active emissions. oᵢ: [own pos/depth/heading/fuel, passive sonar contacts (up to 4 × 5), last known friendly positions from briefing, time elapsed] ~40-dim (No agent has full state — genuine partial observability) ACTION SPACE Aᵢ: FRIGATE (discrete × continuous): Movement: [HOLD, INTERCEPT_COURSE, EVADE, FORM_SCREEN] (4 discrete) Weapon: [HOLD_FIRE, MISSILE(target_id), TORPADO(target_id)] (mixed) → Simplify to 12 discrete action combinations HELICOPTER (continuous): Heading (0-359°), speed (0-120kts), altitude (0-10,000ft), weapon (binary fire/hold) → 4-dim continuous (use MAPPO with Gaussian policy) SUBMARINE (discrete): [PATROL, SPRINT, STALK(bearing), LAUNCH_TORPEDO(target), SURFACE_COMMS] → 8 discrete actions REWARD r(s,a): +20: Convoy vessel intercepted/disabled +50: Convoy captured (mission success if all 5 intercepted) −30: Friendly platform lost −20: Adversary patrol aircraft in engagement envelope (creates threat — should be neutralised first!) −100: Mission failure (convoy escapes area) +5: Convoy track maintained (each vessel tracked by ≥1 friendly) γ = 0.97 [longer episodes than land — naval intercepts take 6-12 hours] (High γ appropriate: decisions early in the intercept determine outcomes hours later) $$

(b) QMIX vs MAPPO selection:

$$ RECOMMENDATION: MAPPO JUSTIFICATION: ① ACTION SPACE: Helicopters need CONTINUOUS actions (heading, speed, altitude). QMIX requires discrete per-agent Q-values → helicopters must be discretised (e.g., 36 heading bins × 4 speed bins = 144 actions). This loses precision in waypoint navigation. MAPPO natively handles continuous actions via Gaussian policy. ② HETEROGENEITY: 3 very different platforms (Frigate, Helo, Sub) with different observation spaces (85-dim vs 70-dim vs 40-dim) and different action types (discrete vs continuous). MAPPO with agent-ID encoding handles heterogeneous agents in one shared network. (Alternative: 3 separate MAPPO actors, one per platform type) ③ COMMUNICATION AT SEA: Naval operations use tactical datalinks (Link-16, UHF SATCOM) but submarine communication requires surfacing or using buoys (tactical radio silence is critical for submarines). CTDE handles this: submarine trains with full coordination but executes in radio silence — no real-time communication needed. QMIX and MAPPO both support this. ④ MIXED COOPERATIVE-COMPETITIVE: If modelling adversary patrol aircraft as agents (for OPFOR learning), MAPPO's actor-critic structure adapts to mixed rewards. QMIX is purely cooperative (shared reward) — cannot directly model adversary agents. CONCLUSION: MAPPO, with continuous helicopter actions as Gaussian policy and discrete frigate/submarine actions as softmax categorical policy. $$

(c) Expected emergent behaviours:

$$ EMERGENT BEHAVIOUR 1: SUBMARINE-FIRST INTERCEPTION Expected: The submarine will learn to POSITION AHEAD of the convoy's projected course and WAIT in ambush position before the frigate engages. REWARD CHAIN DRIVING THIS: - Frontal frigate engagement → convoy at max speed = longer intercept - Convoy turns to evade frigate → if submarine already positioned on escape route → easy intercept → +20 per vessel - By contrast: submarine not pre-positioned → convoy escapes → −100 - Over many training episodes: submarine learns that pre-positioning BEFORE the frigate engages dramatically increases interception probability - This "submarine as anvil, frigate as hammer" tactic emerges purely from the reward structure of interception success rates EMERGENT BEHAVIOUR 2: HELICOPTER PATROL-AIRCRAFT SUPPRESSION Expected: Helicopters will prioritise adversary patrol aircraft before approaching the convoy, even without explicit "suppress patrol aircraft first" reward. REWARD CHAIN DRIVING THIS: - Patrol aircraft within range of helicopters create engagement risk - If helicopter approaches convoy with patrol aircraft active: helicopter has high probability of being shot down (−30 each) - Patrol aircraft neutralised first → helicopter approach risk ~0 → helicopters can safely track all convoy vessels (+5 each × 5) - Net: suppressing patrol aircraft first → lower casualty risk AND better convoy tracking → higher total reward - This "suppress air threat before advancing" mirrors the SEAD-first emergence from combined arms — the same reward structure logic (remove existential threat to enable safe advance) drives both. $$
