Selected Explanations

Q3
Why does subtracting ANY baseline b(s) not bias the policy gradient?
✅ A — Score function identity: E_a[∇_θ log π_θ(a|s)] = 0 for any normalised distribution
Proof: E_a[∇ log π] = Σ_a π(a|s) × (∇π(a|s)/π(a|s)) = Σ_a ∇π(a|s) = ∇(Σ_a π(a|s)) = ∇1 = 0. Therefore E[b(s)·∇ log π] = b(s)·E[∇ log π] = b(s)·0 = 0 for ANY b(s) not depending on a. This profound result means we have a FREE degree of freedom: we can choose b(s) purely to minimise variance without introducing any bias. The optimal choice is b(s) = V^π(s), which gives the advantage function A(s,a) = Q(s,a) - V(s).
Q6
PPO clipping computation: r_t=0.533, Â=-3.5
✅ A — r_t=π_new/π_old=0.533; clip(0.533,0.8,1.2)=0.8; min(−1.867,−2.8)=−1.867
The min for Â<0 selects the LESS negative value — -1.867 > -2.8. This means PPO limits how aggressively it penalises bad actions: even though the policy already decreased this action's probability (r_t=0.533, well below 1), PPO won't force it down further toward the clip boundary. Preventing over-penalisation is as important as preventing over-promotion — both directions of instability are clipped.
Q8
Why is reparameterisation necessary for SAC's actor loss?
✅ B — Sampling a~N(μ,σ²) is non-differentiable; a=μ+σε with fixed ε is deterministic in θ
PyTorch autograd requires the forward computation to be a deterministic function of parameters. The sampling node a~N(μ_θ,σ_θ²) is stochastic — there is no derivative ∂(random draw)/∂μ in the traditional sense. Reparameterisation converts to a=μ_θ+σ_θ·ε: ε is drawn from N(0,1) once and treated as a constant input (no gradient). Now ∂a/∂θ = ∂μ_θ/∂θ + ε·∂σ_θ/∂θ — standard chain rule. This is the same trick that makes VAE training work, and it's essential for SAC, TD3, and DDPG actors.

Q1 — REINFORCE Gradient Computation [10 Marks]
A drone navigation episode has T=4 steps. Actions taken: a₀=LEFT, a₁=FORWARD, a₂=FORWARD, a₃=LAND. Rewards: r₁=0, r₂=+5, r₃=+5, r₄=+10. γ=0.9.

The policy is a softmax over 4 actions: π_θ(a|s). At each timestep:
π_θ(LEFT|s₀)=0.30, π_θ(FORWARD|s₁)=0.45, π_θ(FORWARD|s₂)=0.50, π_θ(LAND|s₃)=0.70

(a) Compute the return G_t for t=0, 1, 2, 3. [3 marks]
(b) Compute the REINFORCE gradient estimate (1/T) Σ_t G_t · ∇_θ log π_θ(aₜ|sₜ). Express as a sum of weighted log-gradients. [3 marks]
(c) With baseline b(s) = 7.0 for all states, compute the advantage-weighted gradient. Compare to the unweighted result and explain why the baseline reduces variance. [4 marks]
Show Answer

(a) Returns G_t (discounted sum from t to T-1):

$$ G_t = Σ_{k=t}^{T-1} γ^{k-t} r_{k+1} G₀ = r₁ + γr₂ + γ²r₃ + γ³r₄ = 0 + 0.9×5 + 0.81×5 + 0.729×10 = 0 + 4.5 + 4.05 + 7.29 = 15.84 G₁ = r₂ + γr₃ + γ²r₄ = 5 + 0.9×5 + 0.81×10 = 5 + 4.5 + 8.1 = 17.6 G₂ = r₃ + γr₄ = 5 + 0.9×10 = 5 + 9.0 = 14.0 G₃ = r₄ = 10.0 $$

(b) REINFORCE gradient estimate:

$$ log π_θ(aₜ|sₜ): log(0.30) = -1.204, log(0.45) = -0.799, log(0.50) = -0.693, log(0.70) = -0.357 REINFORCE gradient (proportional to, dropping the ∇_θ operator): $\nabla J\approx\frac{1}{T}\sum_t G_t\nabla_\theta\log\pi_\theta(a_t|s_t)$ = (1/4) × [G₀·∇ log π(LEFT|s₀) + G₁·∇ log π(FWD|s₁) + G₂·∇ log π(FWD|s₂) + G₃·∇ log π(LAND|s₃)] = (1/4) × [15.84·∇ log(0.30) + 17.6·∇ log(0.45) + 14.0·∇ log(0.50) + 10.0·∇ log(0.70)] In terms of scalar weight per log-gradient term (contribution magnitude): t=0: weight = 15.84/4 = 3.96 (increase P(LEFT|s₀) by 3.96 units) t=1: weight = 17.6/4 = 4.40 (increase P(FWD|s₁) by 4.40 units) t=2: weight = 14.0/4 = 3.50 (increase P(FWD|s₂) by 3.50 units) t=3: weight = 10.0/4 = 2.50 (increase P(LAND|s₃) by 2.50 units) All G_t > 0 → all actions get their probabilities INCREASED — even if some were suboptimal! This is the credit assignment problem illustrated. $$

(c) Baseline b=7.0 subtracted:

Advantage = G_t − b(s): A₀ = 15.84 − 7.0 = +8.84 (LEFT better than average) A₁ = 17.6 − 7.0 = +10.6 (FORWARD much better) A₂ = 14.0 − 7.0 = +7.0 (FORWARD better than average) A₃ = 10.0 − 7.0 = +3.0 (LAND better than average) Advantage-weighted gradient (scalar weights): t=0: weight = 8.84/4 = 2.21 (vs 3.96 without baseline — REDUCED) t=1: weight = 10.6/4 = 2.65 (vs 4.40 — REDUCED) t=2: weight = 7.0/4 = 1.75 (vs 3.50 — HALVED) t=3: weight = 3.0/4 = 0.75 (vs 2.50 — greatly reduced) WHY VARIANCE REDUCED: Without baseline: G_t ∈ {10.0, 14.0, 15.84, 17.6} — range = 7.6 With baseline: A_t ∈ {3.0, 7.0, 8.84, 10.6} — range = 7.6 The ABSOLUTE range is the same! But the KEY is the RELATIVE variance: With baseline: all weights are centred around 0 (some could be negative if an action had G_t < b). The magnitudes are SMALLER → smaller gradient steps → lower variance in the parameter update direction. In general, with many episodes: G_t varies around its mean E[G_t] ≈ b(s). A_t = G_t - b(s) has variance Var(G_t) - 2Cov(G_t,b) + Var(b). Since b(s) is deterministic: Var(b)=0, Cov(G_t,b)=0. But the ABSOLUTE MAGNITUDE |A_t| < |G_t| when b ≈ E[G_t]. OPTIMAL baseline: b*(s) = E[G_t²·||∇ log π||²] / E[||∇ log π||²] ≈ V^π(s) in practice — minimises gradient update variance.
Mark Scheme: (a) 3 marks (1 per G₀, G₁, G₂; G₃ included). (b) 3 marks (log-prob computation 1, four weighted terms 2). (c) 4 marks (advantage values 2, comparison 1, variance explanation 1).
Q2 — PPO Clipping: Two Episodes Worked Example [10 Marks]
An actor-critic agent uses PPO with ε=0.2, γ=0.95, α=0.001. The critic estimates V_φ(s).

Episode batch (3 transitions):
Trans 1: s₁, a=THRUST_HIGH, r=+8, s₂, V_φ(s₁)=6.2, V_φ(s₂)=7.8, π_old(a|s₁)=0.25, π_new(a|s₁)=0.31
Trans 2: s₂, a=THRUST_LOW, r=−3, s₃, V_φ(s₂)=7.8, V_φ(s₃)=5.1, π_old(a|s₂)=0.40, π_new(a|s₂)=0.28
Trans 3: s₃, a=HOVER, r=+2, s₄ (terminal), V_φ(s₃)=5.1, V_φ(s₄)=0, π_old(a|s₃)=0.20, π_new(a|s₃)=0.38

(a) Compute the TD advantage Â_t = r_t + γV_φ(s_{t+1}) − V_φ(sₜ) for each transition. [3 marks]
(b) Compute the probability ratio r_t = π_new/π_old for each transition. [2 marks]
(c) Compute L_CLIP for each transition. Show which transitions are clipped and which are not. [5 marks]
Show Answer

(a) TD Advantages:

$$ Â_t = r_t + γ V_φ(s_{t+1}) − V_φ(s_t) Trans 1: Â₁ = 8 + 0.95×7.8 − 6.2 = 8 + 7.41 − 6.2 = +9.21 (good action!) Trans 2: Â₂ = −3 + 0.95×5.1 − 7.8 = −3 + 4.845 − 7.8 = −5.955 (bad action) Trans 3: Â₃ = 2 + 0.95×0 − 5.1 = 2 + 0 − 5.1 = −3.1 (below-average action) $$

(b) Probability Ratios r_t = π_new/π_old:

$$ Trans 1: r₁ = π_new(THRUST_HIGH|s₁) / π_old = 0.31/0.25 = 1.240 Trans 2: r₂ = π_new(THRUST_LOW|s₂) / π_old = 0.28/0.40 = 0.700 Trans 3: r₃ = π_new(HOVER|s₃) / π_old = 0.38/0.20 = 1.900 $$

(c) L_CLIP for each transition (ε=0.2, so clip range [0.8, 1.2]):

L_CLIP_t = min(r_t × Â_t, clip(r_t, 1-ε, 1+ε) × Â_t) = min(r_t × Â_t, clip(r_t, 0.8, 1.2) × Â_t) TRANS 1: Â₁ = +9.21 (good action), r₁ = 1.240 Â₁ > 0: policy INCREASING probability of good action (r₁ > 1) clip(1.240, 0.8, 1.2) = 1.2 (clipped! 1.240 > 1.2) Unclipped: 1.240 × 9.21 = 11.42 Clipped: 1.200 × 9.21 = 11.05 min(11.42, 11.05) = 11.05 ← CLIPPED Reason: PPO limits how much probability can increase per step (max 20%) The action was already made more likely than PPO allows → cap at 1.2× TRANS 2: Â₂ = −5.955 (bad action), r₂ = 0.700 Â₂ < 0: policy DECREASING probability of bad action (r₂ < 1) clip(0.700, 0.8, 1.2) = 0.8 (clipped! 0.700 < 0.8) Unclipped: 0.700 × (−5.955) = −4.169 Clipped: 0.800 × (−5.955) = −4.764 min(−4.169, −4.764) = −4.169 ← CLIPPED (less negative = higher) Reason: PPO prevents probability from decreasing too fast (>20% reduction) Even for a bad action, cannot decrease probability by >20% per update TRANS 3: Â₃ = −3.1 (below-average), r₃ = 1.900 Â₃ < 0: bad action BUT policy is INCREASING its probability (r₃ = 1.9!) This is dangerous: policy wants to make a BAD action MORE likely clip(1.900, 0.8, 1.2) = 1.2 (clipped at upper bound) Unclipped: 1.900 × (−3.1) = −5.89 Clipped: 1.200 × (−3.1) = −3.72 min(−5.89, −3.72) = −5.89 ← NOT CLIPPED (unclipped is more negative) Note: When Â < 0 and r > 1+ε: unclipped MORE NEGATIVE (more penalty) → PPO does NOT clip this case! It fully penalises making bad actions likely. SUMMARY TABLE: Trans 1: L_CLIP = +11.05 (clipped — good action, capped increase) Trans 2: L_CLIP = −4.169 (clipped — bad action, capped decrease) Trans 3: L_CLIP = −5.89 (NOT clipped — dangerous increase of bad action) Mean batch L_CLIP = (11.05 − 4.169 − 5.89) / 3 = 0.991/3 = 0.330 This is the actor loss (maximised → gradient ascent).
Mark Scheme: (a) 3 marks (1 per Â). (b) 2 marks. (c) 5 marks: clip determination (1.5 per transition × 3 = 4.5, round to 5 based on explanation quality). Key insight: Trans 3 is NOT clipped for the dangerous case — PPO allows full penalty for making bad actions MORE probable than old policy.
Q3 — Gaussian Policy & Continuous Control [10 Marks]
A PPO drone controller outputs: μ_θ(s) = [30.0, 15.0, −5.0] N (thrust xyz), σ_θ(s) = [8.0, 6.0, 4.0] N.

(a) The action a = [25.0, 18.0, −3.0] N is sampled. Compute log π_θ(a|s) (the log-probability of this action). [4 marks]
(b) Given the PPO advantage Â = +4.2 for this action, compute the policy gradient term G_t · ∇_θ log π_θ(a|s). Express the gradient qualitatively: does it increase or decrease μ and σ for each dimension? [3 marks]
(c) The drones need actions bounded to [-100N, +100N]. A squashing function a_bounded = 100·tanh(a_raw) is applied. Explain why the log-probability must be corrected by a Jacobian term, and write the corrected log-probability. [3 marks]
Show Answer

(a) log π_θ(a|s) for diagonal Gaussian:

$$ log π_θ(a|s) = Σᵢ [−½((aᵢ−μᵢ)/σᵢ)² − log σᵢ − ½ log(2π)] For each dimension i=1,2,3: Component 1: a₁=25.0, μ₁=30.0, σ₁=8.0 z₁ = (25.0−30.0)/8.0 = −5.0/8.0 = −0.625 Term₁ = −½(−0.625)² − log(8.0) − ½ log(2π) = −½(0.391) − 2.079 − ½(1.838) = −0.195 − 2.079 − 0.919 = −3.193 Component 2: a₂=18.0, μ₂=15.0, σ₂=6.0 z₂ = (18.0−15.0)/6.0 = 3.0/6.0 = 0.500 Term₂ = −½(0.500)² − log(6.0) − ½ log(2π) = −½(0.250) − 1.792 − 0.919 = −0.125 − 1.792 − 0.919 = −2.836 Component 3: a₃=−3.0, μ₃=−5.0, σ₃=4.0 z₃ = (−3.0−(−5.0))/4.0 = 2.0/4.0 = 0.500 Term₃ = −½(0.500)² − log(4.0) − ½ log(2π) = −0.125 − 1.386 − 0.919 = −2.430 log π_θ(a|s) = Term₁ + Term₂ + Term₃ = −3.193 − 2.836 − 2.430 = −8.459 (This is negative, as expected for a log-probability in ℝ³) $$

(b) Policy gradient direction with Â=+4.2:

$$ The policy gradient update is: Δθ ∝ Â · ∇_θ log π_θ(a|s) Since Â = +4.2 > 0, we want to INCREASE log π (make a more likely). ∂ log π/∂μᵢ = (aᵢ − μᵢ)/σᵢ² Dim 1: (25.0−30.0)/8² = −5/64 = −0.078 Update μ₁ ← μ₁ + α·4.2·(−0.078): μ₁ DECREASES (toward 25.0) Dim 2: (18.0−15.0)/6² = 3/36 = +0.083 Update μ₂ ← μ₂ + α·4.2·0.083: μ₂ INCREASES (toward 18.0) Dim 3: (−3.0−(−5.0))/4² = 2/16 = +0.125 Update μ₃ ← μ₃ + α·4.2·0.125: μ₃ INCREASES (toward −3.0) For σᵢ: ∂ log π/∂ log σᵢ = (aᵢ−μᵢ)²/σᵢ² − 1 Dim 1: (−0.625)² − 1 = 0.391 − 1 = −0.609 → σ₁ DECREASES (narrow) Dim 2: (0.500)² − 1 = 0.250 − 1 = −0.750 → σ₂ DECREASES (narrow) Dim 3: (0.500)² − 1 = 0.250 − 1 = −0.750 → σ₃ DECREASES (narrow) INTERPRETATION: All μᵢ shift toward the sampled action a (which was good: Â=+4.2). All σᵢ decrease — the policy narrows its distribution around this action (less exploration). $$

(c) Jacobian correction for bounded actions:

$$ WHY CORRECTION NEEDED: a_raw ~ N(μ,σ²) in ℝ a_bounded = 100·tanh(a_raw) ∈ (−100, +100) This is a CHANGE OF VARIABLES. The probability density changes: p(a_bounded) = p(a_raw) · |∂a_raw/∂a_bounded| = p(a_raw) / |∂a_bounded/∂a_raw| ∂a_bounded/∂a_raw = 100·(1 − tanh²(a_raw)) = 100·sech²(a_raw) CORRECTED LOG-PROBABILITY: log π_θ(a_bounded|s) = log π_θ(a_raw|s) − Σᵢ log|∂(a_bounded)ᵢ/∂(a_raw)ᵢ| = log π_θ(a_raw|s) − Σᵢ [log(100) + log(1−tanh²(a_raw_i))] = log π_θ(a_raw|s) − Σᵢ [log(100) + log(sech²(a_raw_i))] WITHOUT this correction: the log-probability formula counts density in the UNBOUNDED space. Near the bounds (|a_bounded| → 100), sech²→0, so |∂a_bounded/∂a_raw|→0: the bounded density is HIGHER than the raw density (compression at the tails). Ignoring this overestimates entropy near the action bounds, causing the policy to under-explore the extreme thrust regions needed for aggressive manoeuvres. $$
Mark Scheme: (a) 4 marks (1 per dimension 3, sum 1). (b) 3 marks (∂ log π/∂μ direction 1.5, σ direction 1, interpretation 0.5). (c) 3 marks (why correction 1, Jacobian term 1, formula 1).
Q4 — SAC & Operational Design [10 Marks]
(a) SAC maintains TWO Q-networks Q_{φ1} and Q_{φ2} and takes their minimum for the TD target. Show with a simple numerical example why taking the MINIMUM reduces overestimation bias (use any plausible Q-value scenario with two noisy estimates). [4 marks]

(b) The SAC temperature α controls the entropy weight. Derive the optimal policy π*(a|s) that maximises the SAC objective E_a[Q(s,a) − α log π(a|s)] with respect to π. Show it has a Boltzmann/softmax form. [3 marks]

(c) A defence team is choosing between PPO and SAC for an air-to-ground targeting system that selects aiming angles in continuous space. The system must: (i) achieve >90% target accuracy, (ii) be explainable to a Judge Advocate General (JAG) officer, (iii) adapt to novel target types not seen during training. Recommend a method, justify, and identify what supplementary systems are needed for JAG compliance. [3 marks]
Show Answer

(a) Minimum Q-network reduces overestimation:

SCENARIO: True Q*(s,a) = 10.0 Q-network 1 (noisy estimate): Q_φ1(s,a) = 10.0 + ε₁ where ε₁~N(0,4²) Q-network 2 (noisy estimate): Q_φ2(s,a) = 10.0 + ε₂ where ε₂~N(0,4²), independent SPECIFIC EXAMPLE: ε₁ = +3.5 → Q_φ1 = 13.5 (overestimate) ε₂ = +1.2 → Q_φ2 = 11.2 (overestimate) Standard single-Q: target = Q_φ1 = 13.5 (error: +3.5) Minimum Q-twin: target = min(13.5, 11.2) = 11.2 (error: +1.2) Both are overestimates here, but min gives LESS overestimation. E[max(Q_φ1, Q_φ2)] = E[Q*] + E[max(ε₁,ε₂)] > Q* (max of noise > 0) E[min(Q_φ1, Q_φ2)] = E[Q*] + E[min(ε₁,ε₂)] < E[max] (min of noise < max) For zero-mean noise: E[min(ε₁,ε₂)] is negative on average, so E[min(Q_φ1,Q_φ2)] tends to UNDERESTIMATE slightly. This is intentional: underestimation is less harmful to policy convergence than overestimation (overestimation → policy exploits wrong actions → catastrophic performance). Conservative (min) estimates lead to more cautious, stable learning.

(b) Optimal SAC policy derivation:

$$ Maximise over π(a|s): J(π) = E_a~π[Q(s,a)] + α H(π(·|s)) = Σ_a π(a|s) Q(s,a) − α Σ_a π(a|s) log π(a|s) Subject to constraint: Σ_a π(a|s) = 1 Lagrangian: L(π,λ) = Σ_a π Q(s,a) − α Σ_a π log π − λ(Σ_a π − 1) First-order condition (∂L/∂π(a|s) = 0): Q(s,a) − α(log π(a|s) + 1) − λ = 0 α log π*(a|s) = Q(s,a) − α − λ log π*(a|s) = Q(s,a)/α − 1 − λ/α π*(a|s) = exp(Q(s,a)/α) × exp(−1−λ/α) = C × exp(Q(s,a)/α) where C = exp(−1−λ/α) Normalisation (Σ_a π*(a|s) = 1): C = 1 / Σ_a exp(Q(s,a)/α) Therefore: π*(a|s) = exp(Q*(s,a)/α) / Σ_{a'} exp(Q*(s,a')/α) This is the BOLTZMANN (softmax) distribution over Q-values! α → 0: π*(a|s) → argmax (deterministic, exploit only) α → ∞: π*(a|s) → uniform (maximum entropy, explore only) SAC automatically balances exploration vs exploitation via α! $$

(c) PPO vs SAC for JAG-compliant targeting system:

$$ RECOMMENDATION: PPO with SHAP-based explainability layer JUSTIFICATION: Performance: Both PPO (94%) and SAC (96%) exceed 90% target. PPO chosen. Explainability for JAG: SAC's stochastic policy deliberately maintains multiple plausible aiming solutions — hard to explain to a JAG why a RANDOM sample from a distribution was used for a lethal action. PPO can be configured with near-deterministic low-entropy policy post-training (anneal ε in entropy bonus to near zero), giving a clear decision: "Given sensor state X, optimal aim = Y degrees." Novel targets: PPO at 94% with Domain Randomisation (vary target signatures, viewing angles, occlusion) handles novel types better than SAC in low-data regimes (on-policy: always fresh relevant data). SUPPLEMENTARY SYSTEMS FOR JAG COMPLIANCE: ① SHAP value explainer on the Q-network (or critic V_φ): "System selected angle 42.3° because: target heat signature contributed +6.8 to Q-value, minimum civilian collateral distance contributed +4.1, confidence in target ID contributed +3.9 — total Q=18.7 vs 2nd-best option Q=14.2" ② Confidence threshold: only engage when policy certainty exceeds threshold (low σ from Gaussian policy) — ambiguous states escalate to human operator ③ Target identification verification layer (separate classifier) before RL controller receives engagement authorisation ④ Black box flight recorder of full state-action sequence for post-engagement accountability review $$
